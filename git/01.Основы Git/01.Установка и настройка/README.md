# 01. Установка и настройка Git

Прежде чем начать использовать Git, его необходимо установить и выполнить базовую настройку. Самая важная часть настройки — это указание вашего имени и адреса электронной почты. Эта информация будет привязана к каждому вашему коммиту и станет частью истории проекта.

## Установка Git

### Linux (Ubuntu / Debian)

```bash
sudo apt update
sudo apt install git -y
```

### Linux (CentOS / RHEL / Fedora)

```bash
sudo yum install git -y
# или, для более новых версий
sudo dnf install git -y
```

### macOS

Самый простой способ — установить через **Homebrew**:

```bash
brew install git
```

Или скачать установщик с официального сайта git-scm.com.

### Windows

Скачайте и запустите установщик с официального сайта [git-scm.com](https://git-scm.com/download/win). В процессе установки рекомендуется оставить настройки по умолчанию.

После установки вы сможете использовать Git через **Git Bash** (эмулятор терминала) или через командную строку / PowerShell.

## Базовая настройка

Настройки Git хранятся в конфигурационных файлах трех уровней:

| Уровень | Файл / Команда | Приоритет |
| :--- | :--- | :--- |
| **Системный** (`--system`) | `/etc/gitconfig` | Самый низкий |
| **Глобальный** (`--global`) | `~/.gitconfig` | Средний (переопределяет системный) |
| **Локальный** (`--local`) | `./.git/config` (внутри репозитория) | Самый высокий |

### Настройка имени и email (глобально)

Это действие является обязательным. Без них вы не сможете создавать коммиты.

```bash
git config --global user.name "Your Full Name"
git config --global user.email "your.email@example.com"
```

> [!important]
> Убедитесь, что указали правильный email. Если вы используете GitHub или GitLab, этот email должен совпадать с тем, который привязан к вашему аккаунту. В противном случае коммиты не будут связаны с вашим профилем.

### Настройка текстового редактора

Выберите редактор, в котором вы будете писать сообщения для коммитов и редактировать другие файлы.

```bash
# Для Vim
git config --global core.editor "vim"

# Для Nano
git config --global core.editor "nano"

# Для Visual Studio Code
git config --global core.editor "code --wait"

# Для Sublime Text
git config --global core.editor "subl -w"
```

### Настройка окончаний строк (CRLF)

Эта настройка важна для предотвращения проблем с переносами строк при работе в команде с разными операционными системами.

- **Windows (`core.autocrlf true`):** При `checkout` конвертирует `LF` в `CRLF`, при `commit` — обратно.
- **Linux/macOS (`core.autocrlf input`):** При `checkout` оставляет `LF` как есть, при `commit` конвертирует `CRLF` в `LF`.

```bash
# Для Windows
git config --global core.autocrlf true

# Для Linux / macOS
git config --global core.autocrlf input
```

### Настройка цвета

Для улучшения читаемости вывода команд можно включить цветовое выделение.

```bash
git config --global color.ui auto
```

### Просмотр и удаление настроек

```bash
# Просмотреть все глобальные настройки
git config --global --list

# Просмотреть конкретную настройку
git config user.name

# Удалить глобальную настройку
git config --global --unset user.name
```

## Итоговый мини-чеклист

После установки и настройки выполните проверку:

```bash
# Проверка версии
git --version

# Проверка имени и email
git config user.name
git config user.email

# Проверка редактора
git config core.editor
```

> [!tip]
> Всегда проверяйте настройки на новом компьютере. Ошибка в `user.email` может привести к тому, что ваши коммиты будут связаны с неверным пользователем на GitHub или GitLab. Это особенно важно при работе в корпоративной среде.

> [!note]
> Настройки можно изменять в любой момент. Изменения в `user.name` и `user.email` будут применяться только к новым коммитам. Старые коммиты останутся с прежними данными.
