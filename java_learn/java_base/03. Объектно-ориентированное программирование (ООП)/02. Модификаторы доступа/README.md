# Модификаторы доступа в Java

## 1. Зачем нужны модификаторы доступа

Модификаторы доступа — это инструмент управления доступом к данным и операциям внутри классов. Они решают несколько задач:

- **Определяют, кто и откуда может обращаться** к классу, его полям и методам.
- **Позволяют скрывать внутренние детали реализации** — наружу видно только то, что действительно нужно.
- **Дают возможность безопасно управлять состоянием объекта** — защищают данные от нежелательных изменений и ошибок.

> Если не ограничивать доступ, код становится уязвимым и трудным в сопровождении. Грамотное использование модификаторов делает программы безопаснее и понятнее для других разработчиков.

---

## 2. Виды модификаторов доступа в Java

Модификаторы перечислены от самого закрытого к самому открытому:

| Модификатор | Уровень доступа |
|-------------|-----------------|
| `private` | Доступ только внутри текущего класса. |
| *package-private* (модификатор не указан) | Доступ только в пределах пакета. |
| `protected` | Доступ в пределах пакета; за пределами пакета применяется лишь в специфических случаях. Для базовой практики достаточно помнить: «видно в пакете». |
| `public` | Доступ из любого места программы. |

**Ключевые моменты:**
- `private` — самый закрытый уровень: поле или метод виден только внутри самого класса.
- Если модификатор не указан вовсе, это **package-private** (доступ в пределах пакета).
- `protected` — расширяет package-private, но за пределами пакета применяется лишь в специфических случаях (наследование). Для базовой практики достаточно помнить: «видно в пакете».
- `public` — самый открытый уровень: доступен отовсюду.

## 3. Пример с автомобилем

Чтобы проще понять, чем отличаются модификаторы доступа, рассмотрим ситуацию на примере автомобиля.

- **Номер двигателя** никто не видит — `private`.
- **Модель** видна только «своим» внутри пакета — *package-private*.
- **Пробег** доступен в пакете и в отдельных технических сценариях — `protected`.
- **Цвет** открыт для всех — `public`.

```java
public class Car {
    private String engineNumber; // видно только внутри самого класса
    String model;                // видно только в пределах пакета (package-private)
    protected int mileage;       // видно в пакете; вне пакета лишь в специфических случаях
    public String color;         // видно отовсюду
}
```

**Разбор примера:**
- `engineNumber` — приватное поле. Никто извне не может прочитать или изменить номер двигателя напрямую.
- `model` — package-private. Доступно только классам из того же пакета.
- `mileage` — protected. Доступно в пакете, а также в подклассах (даже из других пакетов) — но это уже специфический сценарий.
- `color` — public. Доступно из любого места программы.

---

## 4. Итог

Модификаторы доступа помогают контролировать, какие части кода доступны другим:

- **Скрывают внутренние данные и детали реализации.**
- **Защищают данные от нежелательных изменений и ошибок.**
- **Открывают наружу только то, что действительно нужно.**

Такой подход делает программы **безопаснее** и **понятнее** для других разработчиков. Если же не ограничивать доступ, код становится уязвимым и трудным в сопровождении.
