# Строки в Java (класс String)

## 1. Что такое строка

**Строка** — это некоторая последовательность символов, которые являются текстом.

```java
String name = "Вася";
```
Здесь `String` — это тип, `name` — имя переменной, `"Вася"` — значение.

> **Важно:** `String` — это не примитив, а объект. С ним надо обращаться соответствующе.

---

## 2. Конкатенация строк

Строки можно складывать. Этот процесс называется **конкатенацией** (объединением строк).

```java
String a = "2";
String b = "2";
System.out.println(a + b); // В консоль будет выведено: 22
```

Не путать со сложением чисел:
```java
int a = 2;
int b = 2;
System.out.println(a + b); // 4
```

**Складывать строки можно без объявления переменных:**
```java
System.out.println("Строка 1, " + "Строка 2"); // Строка 1, Строка 2
```

> Каждая новая операция со строкой создаёт **новый экземпляр объекта строки**. Если в коде много операций с модификацией строк, используйте `StringBuilder`.

**Конкатенация строки с числом** — число автоматически переводится в строку:
```java
int a = 22;
String b = "Итог: ";
System.out.println(b + a); // Итог: 22
```

## 3. Длина строки и доступ к символам

Строку можно расценивать как массив символов.

**Длина строки — метод `length()`:**
```java
String b = "Велосипедист";
System.out.println(b.length()); // 12
```
Часто используется, например, при проверке пароля на минимальную длину.

**Получение символа по индексу — метод `charAt()` (отсчёт с 0):**
```java
String b = "Велосипедист";
System.out.println(b.charAt(0)); // В
```

## 4. Пример: поиск палиндрома

**Палиндром** — это слово или фраза, которые одинаково читаются слева направо и справа налево.

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        /*
         * Что делаем:
         * 1) Читаем строку целиком (с пробелами).
         * 2) Проверяем, палиндром ли она, если игнорировать регистр и небуквенно-цифровые символы.
         *    Подход: два указателя (слева и справа), которые двигаются навстречу.
         * 3) Находим самую длинную палиндромную ПОДСТРОКУ с помощью "расширения от центра".
         */

        Scanner sc = new Scanner(System.in);
        System.out.println("Введите строку:");
        String s = sc.nextLine(); // берём всю строку, а не одно слово

        // 1) Палиндром ли строка (игнорируем регистр и не буквенно-цифровые символы)
        boolean isPal = isPalindromeLoose(s);
        if (isPal) {
            System.out.println("Палиндром (при игнорировании регистра и знаков).");
        } else {
            System.out.println("Не палиндром (при игнорировании регистра и знаков).");
        }

        // 2) Самая длинная палиндромная подстрока (учитываем все символы, но игнорируем регистр)
        String longest = longestPalindromicSubstringIgnoreCase(s);
        System.out.println("Самая длинная палиндромная подстрока: \"" + longest + "\"");
    }

    /*
     * Проверка "строка -- палиндром?":
     * - Игнорируем всё, что не буква и не цифра (пробелы, пунктуация).
     * - Сравниваем без учёта регистра.
     * Алгоритм: два указателя -- i слева, j справа; двигаем к центру и сравниваем пары символов.
     * Сложность: O(n), где n -- длина строки.
     */
    static boolean isPalindromeLoose(String s) {
        int i = 0;
        int j = s.length() - 1;

        while (i < j) {
            // сдвигаем i вправо, пока не встретим букву или цифру
            while (i < j && !Character.isLetterOrDigit(s.charAt(i))) i++;
            // сдвигаем j влево, пока не встретим букву или цифру
            while (i < j && !Character.isLetterOrDigit(s.charAt(j))) j--;

            char left = Character.toLowerCase(s.charAt(i));
            char right = Character.toLowerCase(s.charAt(j));

            if (left != right) return false; // пара не совпала -- выходим

            i++;
            j--;
        }
        return true; // все пары совпали
    }

    /*
     * Поиск самой длинной палиндромной ПОДСТРОКИ:
     * Метод "расширение от центра" (expand around center).
     * Для каждого индекса i рассматриваем два центра:
     *   - (i, i)  -- нечётная длина (например, "aba")
     *   - (i, i+1) -- чётная длина (например, "abba")
     * Расширяемся влево/вправо, пока символы равны. Берём максимум.
     * Сложность: O(n^2) в худшем случае.
     */
    static String longestPalindromicSubstringIgnoreCase(String s) {
        if (s == null || s.isEmpty()) return "";

        String lower = s.toLowerCase(java.util.Locale.ROOT);
        int start = 0, end = 0;

        for (int i = 0; i < lower.length(); i++) {
            int lenOdd  = expandAroundCenter(lower, i, i);
            int lenEven = expandAroundCenter(lower, i, i + 1);
            int len = Math.max(lenOdd, lenEven);

            int newStart = i - (len - 1) / 2;
            int newEnd   = i + len / 2;

            if (len > end - start + 1) {
                start = newStart;
                end = newEnd;
            }
        }
        return s.substring(start, end + 1);
    }

    // Расширяемся от центра (L, R), пока символы равны. Возвращаем длину найденного палиндрома.
    static int expandAroundCenter(String lower, int L, int R) {
        while (L >= 0 && R < lower.length() && lower.charAt(L) == lower.charAt(R)) {
            L--;
            R++;
        }
        return R - L - 1;
    }
}
```

**Пояснения:**
- Для проверки палиндрома важно читать строку через `nextLine()`, иначе `next()` обрежет ввод по пробелу.
- В методе `isPalindromeLoose` специально пропускаются пробелы и знаки — так фразы вида «А роза упала на лапу Азора» распознаются как палиндром.
- Метод поиска «самой длинной подстроки» возвращает фрагмент исходной строки, но сравнение ведёт без учёта регистра.

## 5. Основные методы класса String

| Метод | Возвращает | Описание | Пример |
|-------|------------|----------|--------|
| `charAt(int index)` | `char` | Возвращает символ по указанному индексу | `"Some".charAt(0)` → `'S'` |
| `concat(String str)` | `String` | Конкатенирует строки | `"Привет ".concat("мир!")` → `"Привет мир!"` |
| `equals(String str)` | `boolean` | Возвращает `true`, если строки равны | `s1.equals("some")` → `true` |
| `equalsIgnoreCase(String str)` | `boolean` | Сравнивает строки, игнорируя регистр | `"some".equalsIgnoreCase("some")` → `true` |
| `indexOf(int ch)` / `lastIndexOf(int ch)` | `int` | Индекс первого или последнего вхождения символа | `"Some string".indexOf('o')` → `1` |
| `indexOf(String str)` / `lastIndexOf(String str)` | `int` | Индекс первого или последнего вхождения подстроки | `"Some string".indexOf("string")` → `5` |
| `length()` | `int` | Возвращает длину строки | `"Some".length()` → `4` |
| `replace(char oldChar, char newChar)` | `String` | Заменяет все вхождения символа | `"abra cadabra".replace('a','e')` → `"ebre cedebre"` |
| `replaceAll(String oldStr, String newStr)` | `String` | Заменяет каждую подстроку | `"abra cadabra".replaceAll("abra","no")` → `"no cadno"` |
| `replaceFirst(String oldStr, String newStr)` | `String` | Заменяет первую подстроку | `"abra cadabra".replaceFirst("abra","no")` → `"no cadabra"` |
| `split(String s)` | `String[]` | Разделяет строку на массив строк по разделителю | `"Маша,Саша,Витя".split(",")` → `{"Маша","Саша","Витя"}` |
| `substring(int beginIndex)` / `substring(int beginIndex, int endIndex)` | `String` | Возвращает подстроку | `"Привет мир".substring(7)` → `"мир"` |
| `toLowerCase()` / `toUpperCase()` | `String` | Преобразует в нижний/верхний регистр | `"Привет мир".toLowerCase()` → `"привет мир"` |
| `trim()` | `String` | Убирает пробелы в начале и конце | `" лишние пробелы ".trim()` → `"лишние пробелы"` |
| `String.valueOf(примитивный тип)` | `String` | Строковое представление аргумента | `String.valueOf(3)` → `"3"` |

## 6. Сравнение строк: `equals` вместо `==`

Строка — это объект, поэтому сравнивать её надо через `equals()`.

**Сравнение примитивов:**
```java
int a = 22;
int b = 22;
System.out.println(a == b); // true
```

**Сравнение строк:**
```java
String a = "22";
String b = "22";
System.out.println(a.equals(b)); // true
```

> `==` сравнивает **ссылки**, а `equals()` — **содержимое**. Для строк всегда используйте `equals()` или `equalsIgnoreCase()`.

---

## 7. Хранение строк в памяти

Строки в Java хранятся в **пуле строк** (String Pool) — специальной области памяти. Это ещё одна причина, почему `==` может давать неожиданные результаты при сравнении строк, созданных разными способами.

## 8. Форматирование строк

Иногда нужно передавать в строки переменные — и не всегда удобно делать это через конкатенацию. Для этого есть `String.format(...)` и `System.out.printf(...)`.

**Базовые плейсхолдеры:**
- `%s` — для строк
- `%d` — для целых
- `%f` — для чисел с плавающей точкой

```java
String msg = String.format("Привет, %s! Тебе %d лет.", "Аня", 23);
// "Привет, Аня! Тебе 23 лет."
```

**Ширина и выравнивание:** `%10s` — ширина 10 по правому краю, `%-10s` — по левому, `%05d` — добивает нулями слева.
```java
String row = String.format("|%10s|%-10s|%05d|", "right", "left", 42);
// "|     right|left      |00042|"
```

**Точность для вещественных:** `.<n>` — количество знаков после запятой.
```java
String pi = String.format("π ≈ %.3f", Math.PI);
// "π ≈ 3.142"
```

**Разделители тысяч:** флаг `,`.
```java
String n = String.format("%,d", 1_234_567);
// "1,234,567" в US-локали
```

**Позиционные индексы:** `%1$s`, `%2$s` и т. п. позволяют переиспользовать аргументы и менять их порядок.
```java
String s = String.format("%2$s потом %1$s", "A", "B"); // "B потом A"
```

**Экранирование процента:** `%%`.
```java
String sale = String.format("Скидка 15%% на %s", "товары");
// "Скидка 15% на товары"
```

**Локаль** влияет на формат чисел и дат:
```java
import java.util.Locale;

String us = String.format(Locale.US, "%.2f", 1234.56);      // "1234.56"
String de = String.format(Locale.GERMANY, "%.2f", 1234.56); // "1234,56"
```

## 9. Заключение

Строка — это последовательность символов. Мы научились:
- создавать строки, складывать их (`+`, `concat`) и соединять «на лету» без переменных;
- безопасно сравнивать строки (`equals`, `equalsIgnoreCase`) вместо `==`;
- измерять длину (`length`), доставать символы (`charAt`), искать позиции (`indexOf`, `lastIndexOf`);
- извлекать подстроки (`substring`), раскладывать строку на части (`split`);
- нормализовать вид текста (`trim`, `toLowerCase`, `toUpperCase`);
- делать замены (`replace`, `replaceFirst`, `replaceAll`);
- превращать числа и другие примитивы в текст (`String.valueOf`);
- форматировать сообщения с плейсхолдерами (`String.format`).

### Важные нюансы и частые ошибки

- **`String` иммутабельна:** каждая «изменяющая» операция создаёт новую строку. В длинных циклах для производительности используйте `StringBuilder`.
- **Индексация с нуля.** `charAt(b.length())` бросит `StringIndexOutOfBoundsException`.
- **Для сравнения используйте `equals`, а не `==`** (второй сравнивает ссылки).
- **`replaceAll` и `split` принимают регулярные выражения.** Если разделитель — спецсимвол (например, точка `.`), экранируйте его (`\\.`).
- **Учтите локаль** при смене регистра и сравнении пользовательского ввода (например, турецкая `i`). Для строгих правил используйте `toLowerCase(Locale...)`.
- **Работая с эмодзи** и редкими символами (пара суррогатов), помните: `charAt` оперирует 16-битными единицами, а не полными юникод-кодпоинтами. Для продвинутых сценариев используйте API по кодпоинтам (`codePoints()`).
- **Конкатенация со смешанными типами:** при «строка + число» число автоматически превращается в текст — следите за порядком склейки.

### Мини-шпаргалка

- Быстро склеить: `"Hello, " + name`
- Аккуратно отформатировать: `String.format("Привет, %s! Тебе %d.", name, age)`
- Проверить пустоту/пробелы: `s == null || s.trim().isEmpty()`
- Найти и заменить: `text.replace("абв", "xyz")`
- Разбить CSV: `"a,b,c".split(",")`
