# Переменные и операторы

- Анатомия переменной:
```java
// public - модификатор доступа
// static - доступ к переменной (с созданием объекта класса, или без)
// final - неизменная переменная
// double - тип данных
// PI - название переменной
// 3.14d - значение переменной
public static final double PI = 3.14d;
```

- Пример объявления нескольких переменных в рамках одной сигнатуры:
```java
private static int a = 0, b = 1, c = 2;
```

- Локальные переменные:

В данном примере локальная переменная `age`, она будет использоваться только при вызове метода `catAge` и может быть вызванна только в нём. Для неё нет необходимости использовать `модификаторы доступа`.

```java
public class Test { 
    public static void catAge() {
       int age = 0;
       age = age + 7;
       System.out.println("Возраст кошки: " + age);
    }
    
    public static void main(String args[]) {
       catAge();
    }
 }
```

## Операторы

Они позволяют осуществлять взаимодействие между переменными.

- Арифмитические операторы
```
+ - сумма
- - разность
* - умножение
/ - деление
% - остаток от деления
++ - инкремент (увеличивает на единицу, бывает постинкремент и прединкремент)
-- - декремент (увеличивает на единицу, бывает постдекремент и преддекремент)
```

- Операторы сравнения:
```
== - сравнение (работает только для примитивных данных, для объектов сравнивает адреса в памяти)
!= - не равно
> - больше
< - меньше
>= - больше или равно
<= - меньше или равно
```

- Побитовые операторы:

Java позволяет использовать побитовые операторы для целочисленных типов: `int`, `long`, `short`, `char`, `byte`:
```
& - Бинарный оператор И
| - Бинарный оператор ИЛИ
^ - Бинарный оператор логическое ИЛИ
~ - Бинарный оператор дополнения
<< - Бинарный оператор сдвига влево
>> - Бинарный оператор сдвига вправо
>>> - Нулевой оператор сдвига вправо
```

- Логические операторы:
```
&& - оператор И (true && true = true)
|| - оператор ИЛИ (true || false = true)
! - оператор не (!true = false)
```

- Операторы присваивания:
```
= - стандарт
+= - увеличиваем значение на x
-= - уменьшаем значение на х
*= - умножаем значение на х
/= - делим значени на х
%= - остаток от деления на х
<<= - сдвиг влево?
>>= - сдвиг вправо?
&= - побитовое и?
^= - ???
|= - побитовое или ?
```
