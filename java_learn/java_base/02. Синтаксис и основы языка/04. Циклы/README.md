# Циклы в Java

## 1. Что такое цикл

**Цикл** — это управляющая структура, которая повторяет несколько шагов в программе.

Циклы нужны не меньше, чем условия, а в большинстве случаев используются совместно с ними. Они помогают не дублировать код, а с помощью специального синтаксиса «автоматизировать» повторяющиеся действия.

**Пример задачи:** компании, в которой работают семь сотрудников, необходимо семь раз повторить расчёт заработной платы для каждого сотрудника — вместо семи копий одного и того же кода используется цикл.

**Счётный цикл** — это цикл, требуемое количество итераций которого может быть определено до начала его выполнения.

## 2. Цикл `while`

Цикл `while` — это условно бесконечный цикл: код в блоке выполняется снова и снова, пока условие в скобках не станет `false`.

**Синтаксис:**
```java
while (boolean-выражение) {
    // тело цикла
}
```

**Пример вечного цикла:**
```java
while (true) {
    // будет работать, пока программа не будет закрыта
}
```

Как правило, в таких циклах совершают полезную работу, а когда она завершается, условие переключается в `false` и цикл заканчивается.

**Пример счётного цикла:**
```java
int i = 0;
while (i < 10) {
    i++;
}
```
Изначально `i = 0`. За каждый проход к переменной добавляется единица. Как только `i` станет равна 10 или более, цикл прекратится.

**Пример: расчёт зарплат семи сотрудников**

```java
int count_emp = 0;    // пока не обработан ни один сотрудник
int number_emp = 7;   // всего 7 сотрудников
double hours, rate, pay;
Scanner input = new Scanner(System.in);

while (count_emp < number_emp) {   // проверка значения count_emp
    System.out.print("Введите отработанные часы: ");
    hours = input.nextDouble();
    System.out.print("Введите часовую ставку в рублях: ");
    rate = input.nextDouble();
    pay = hours * rate;
    System.out.println("Зарплата равна " + pay + " руб.");
    ++count_emp;   // переход к следующему сотруднику
}
System.out.println("\nВсе сотрудники обработаны.\n");
```

Здесь тело цикла — это блок предложений, который начинается со строки ввода данных. Тело получает входные данные для расчёта зарплаты сотрудника, а также вычисляет и отображает его зарплату. После отображения семи зарплат выводится следующее за телом цикла сообщение «Все сотрудники обработаны».

## 3. Цикл `for`

Цикл `for` удобно использовать, когда известно точное количество повторений. В нём можно использовать индексы.

**Синтаксис:**
```java
for (инициализация; условие; обновление) {
    // тело цикла
}
```

**Пример:**
```java
for (int i = 0; i < 10; i++) {
    // тело цикла
}
```

Разбор:
- `int i = 0` — объявляется переменная `i`, отвечающая за количество проходов.
- `i < 10` — ограничение проходов (условие продолжения).
- `i++` — инкремент: после каждого прохода к `i` добавляется единица.

Код выполняется, пока `i` меньше 10.

**В чём удобство `for`:**
- можно ограничивать количество итераций (проходов);
- можно использовать переменную `i` в исполняемом коде — например, для добавления номера к строке:

```java
for (int i = 0; i < 10; i++) {
    System.out.println("Stroka " + i);
}
```

- можно указывать шаг: вместо `i++` сделать `i = i + 10` (или `i += 10`).

**Пример: цикл `for`, эквивалентный циклу `while` из предыдущего раздела**

```java
int count_emp = 0;    // инициализация
double total_pay = 0.0;
for (count_emp = 0; count_emp < number_emp; ++count_emp) {
    System.out.print("Введите отработанные часы: ");
    hours = input.nextDouble();
    System.out.print("Введите часовую ставку в рублях: ");
    rate = input.nextDouble();
    pay = hours * rate;
    System.out.println("Зарплата равна " + pay + " руб.");
    total_pay += pay;
}
System.out.println("\nВсе сотрудники обработаны.\n");
```

**Важная особенность:** предложение `for` обеспечивает чётко обозначенное место для каждого из трёх компонентов (инициализация; условие; обновление).

## 4. Операторы `break` и `continue`

Иногда нужно остановить цикл, не привязываясь к условиям этого цикла. Например, мы что-то искали, нашли — и дальше искать нет смысла. В качестве «стоп-крана» используется оператор `break`.

**Пример `break`:**
```java
for (int i = 0; i < 100; i += 10) {
    System.out.println("Строка " + i);
    if (i == 50) {
        break;
    }
}
```
Как только `i` станет равна 50, произойдёт выход из цикла, и в консоль будет произведён последний вывод.

Если нужно не выходить из цикла, а просто пропустить одну итерацию, используется оператор `continue`.

**Пример `continue`:**
```java
for (int i = 0; i < 100; i += 10) {
    if (i == 50) {
        continue;
    }
    System.out.println("Строка " + i);
}
```
Когда `i` будет равна 50, вывод в консоль пропустится, и будут выведены все проходы, кроме этого.

## 5. Цикл `do...while`

Цикл `do-while` работает иначе, чем `while` и `for`: он гарантированно выполняет тело цикла хотя бы один раз и только потом проверяет условие продолжения. Это происходит даже если условие изначально ложно.

**Синтаксис:**
```java
do {
    // тело цикла
} while (boolean-выражение);
```

**Пример:**
```java
int i = 100;
do {
    System.out.println("YA vypolnilsya");
} while (i < 10);
```
Несмотря на то, что условие однозначно не выполняется, поскольку сначала идёт блок с кодом, а только потом проверка, в консоль будет выведено `"YA vypolnilsya"`.

**Пример: программа `ValidateLetter` — проверка правильности ввода числа в заданном диапазоне**

Важно: для работы с классом `Scanner` его необходимо импортировать:
```java
import java.util.Scanner;
```
А для создания объекта `Scanner` используется строка:
```java
Scanner input = new Scanner(System.in);
```

```java
import java.util.Scanner;

public class ValidateLetter {
    public static void main(String[] args) {
        int number;
        Scanner input = new Scanner(System.in);

        do {
            System.out.print("Введите цифру от 1 до 5: ");
            number = input.nextInt();
        } while (number < 1 || number > 5);
    }
}
```

## 6. Когда использовать разные типы циклов

Выбор типа цикла зависит от задачи:
- если известно точное количество повторов — используйте `for`;
- если количество повторов заранее неизвестно — используйте `while`;
- если тело цикла нужно выполнить хотя бы один раз — используйте `do-while`.

| Цикл | Когда использовать? | Особенности |
|------|---------------------|-------------|
| `for` | Когда известно число итераций | – Удобен для работы с индексами<br>– Проверка условия ПЕРЕД итерацией<br>– Автоматическое обновление счётчика |
| `while` | Когда условие может измениться | – Проверка условия ПЕРЕД итерацией<br>– Может не выполниться ни разу<br>– Универсален для любых условий |
| `do-while` | Когда нужно выполнить код ≥1 раз | – Тело выполняется ДО проверки условия<br>– Проверка условия ПОСЛЕ итерации<br>– Гарантированно выполнится хотя бы 1 раз<br>– Продолжается только если условие истинно |

## 7. Вложенные циклы

Один цикл может быть вложен в другой. Вложенные циклы состоят из одного внешнего цикла и одного или нескольких внутренних. Каждый раз при проходе внешнего цикла происходит повторный вход во внутренние циклы — таким образом, они запускаются заново.

**Пример: программа `MultiplicationTable` — таблица умножения с помощью вложенных циклов**

```java
public class MultiplicationTable {
    public static void main(String[] args) {
        // Отобразить название таблицы
        System.out.println("\t\t\t\tТАБЛИЦА УМНОЖЕНИЯ\n");

        // Добавляем дополнительный табулятор для выравнивания
        System.out.print("\t");

        // Отобразить имена столбцов
        for (int j = 1; j <= 9; j++)
            System.out.print("\t" + j);

        System.out.println("\n\t--------------------------------------------------");

        // Отобразить имена строк и произведение
        for (int i = 1; i <= 9; i++) {
            // Добавляем дополнительный табулятор для выравнивания строк
            System.out.print(i + " |");
            for (int j = 1; j <= 9; j++) {
                System.out.printf("\t%d", i * j);
            }
            System.out.println();
        }
    }
}
```

**Важно:** выполнение вложенного цикла — очень ресурсоёмкий процесс. Рассмотрим цикл трехуровневой вложенности:

```java
for (int i = 0; i < 10000; i++)
    for (int j = 0; j < 10000; j++)
        for (int k = 0; k < 10000; k++)
            // Выполнить действие
```

Здесь действие выполняется один триллион раз. Если для выполнения этого действия требуется 1 микросекунда, то общее время выполнения цикла займёт более 277 часов.

**Причина:** общее число итераций при вложенных циклах быстро растёт. Для трёх циклов по 10 000 проходов получится 10 000 × 10 000 × 10 000 = 1 триллион итераций. Поэтому вложенные циклы используют только при острой необходимости, так как время выполнения программы резко увеличивается.
