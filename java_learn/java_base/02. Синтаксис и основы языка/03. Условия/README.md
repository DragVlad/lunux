# Условные операторы и логические выражения в Java

## 1. Оператор `if`

Оператор `if` — это основной инструмент для ветвления программы. Он позволяет выполнить определённый блок кода только в том случае, если заданное логическое (boolean) выражение истинно.

**Синтаксис:**
```java
if (boolean-выражение) {
    предложение(я);
}
```

**Пример:**
```java
int a = 5;
if (a > 0) {
    System.out.println("Условие выполнено");
}
```

Если выражение в скобках возвращает `true`, выполняется код внутри блока `{}`. Если `false` — блок пропускается.

---

## 2. Двухвариантный оператор `if-else`

Если нужно выполнить один код при истинном условии и другой — при ложном, используется `else`.

**Синтаксис:**
```java
if (boolean-выражение) {
    предложение(я) в случае true;
} else {
    предложение(я) в случае false;
}
```

**Пример:**
```java
int a = -3;
if (a > 0) {
    System.out.println("Условие выполнено");
} else {
    System.out.println("Условие не выполнено");
}
```

---

## 3. Многовариантные предложения `if-else` и `else if`

Вложение `if` можно использовать многократно. При невыполнении условия в скобках выполняется код в блоке `else`.

**Пример вложенного `if`:**
```java
int i = 10, j = 5, k = 3;
if (i > k) {
    if (j > k)
        System.out.println("i и j больше k");
} else {
    System.out.println("i меньше или равно k");
}
```

Оператор `else if` позволяет последовательно проверить несколько условий в одной конструкции.

**Синтаксис:**
```java
if (условие1) {
    // код
} else if (условие2) {
    // код
} else if (условие3) {
    // код
} else {
    // код по умолчанию
}
```

**Пример:**
```java
int a = 0;
if (a > 0) {
    System.out.println("Главное условие выполнено");
} else if (a < 0) {
    System.out.println("Условие выполнено");
} else if (a == 0) {
    System.out.println("Условие выполнено");
} else {
    System.out.println("Условие не выполнено");
}
```

**Важно:**
- Блоков `else if` может быть сколько угодно; `if` и `else` — по одному.
- Как только в одном из `else if` условие выполнено, остальные проверки не выполняются.
- Многовариантные `if-else` могут быть громоздкими и неэффективными при большом числе вариантов. В таких случаях лучше использовать `switch`.

## 4. Оператор `switch`

Оператор `switch` используется, когда нужно проверить конкретное значение и выполнить код в соответствии с этим значением.

**Синтаксис:**
```java
switch (выражение) {
    case значение1:
        // код
        break;
    case значение2:
        // код
        break;
    default:
        // код по умолчанию
}
```

**Пример:**
```java
int grade = 3;
switch (grade) {
    case 5:
        System.out.println("Отлично!");
        break;
    case 4:
        System.out.println("Хорошо!");
        break;
    case 3:
    case 2:
        System.out.println("Можно лучше!");
        break;
    case 1:
        System.out.println("Придется переделать.");
        break;
    default:
        System.out.println("Неверная оценка.");
}
```

**Правила работы `switch`:**
- Переменные в `switch` могут быть только целыми числами, строками или перечислениями (enum).
- Количество `case` не ограничено.
- Значение `case` должно быть того же типа, что и переменная в `switch`, и быть константой или литералом.
- `break` завершает выполнение `switch` и передаёт управление следующей строке после него.
- Если `break` отсутствует, поток управления переходит к следующему `case` (проваливание).
- `default` — необязательный блок, выполняется, если ни один `case` не совпал. Обычно располагается в конце.

## 5. Логические операторы

Логические операторы используются для составления сложных условий.

| Оператор | Математический знак | Имя оператора | Пример (radius = 5) | Результат |
|----------|---------------------|---------------|---------------------|-----------|
| `<`      | <                   | Меньше        | `radius < 0`        | `false`   |
| `<=`     | ≤                   | Меньше или равно | `radius <= 0`    | `false`   |
| `>`      | >                   | Больше        | `radius > 0`        | `true`    |
| `>=`     | ≥                   | Больше или равно | `radius >= 0`    | `true`    |
| `==`     | =                   | Равно         | `radius == 0`       | `false`   |
| `!=`     | ≠                   | Не равно      | `radius != 0`       | `true`    |

**Важно:** оператор проверки на равенство — это `==` (два знака «равно»), а не `=` (один знак, который используется для присваивания).

**Логические операторы `&&`, `||`, `^`:**
- `&&` — логическое И (истина, если оба операнда истинны).
- `||` — логическое ИЛИ (истина, если хотя бы один операнд истинен).
- `^` — исключающее ИЛИ (истина, если операнды различны).

**Пример программы, проверяющей делимость числа:**
```java
import java.util.Scanner;

public class TestBooleanOperators {
    public static void main(String[] args) {
        int number;
        Scanner input = new Scanner(System.in);

        System.out.print("Введите целое число: ");
        number = input.nextInt();

        if (number % 2 == 0 && number % 3 == 0)
            System.out.println(number + " делится нацело на 2 и на 3.");

        if (number % 2 == 0 || number % 3 == 0)
            System.out.println(number + " делится нацело на 2 или на 3.");

        if (number % 2 == 0 ^ number % 3 == 0)
            System.out.println(number + " делится нацело на 2 или на 3, но не на оба.");
    }
}
```

## 6. Тернарный оператор `? :`

Тернарный оператор — это лаконичная форма записи проверки условия. Он позволяет проверить только одно условие (в отличие от `else if`).

**Синтаксис:**
```java
условие ? выражение_если_true : выражение_если_false
```

**Пример:**
```java
int a = 0;
String result = (a == 0) ? "равно" : "не равно";
System.out.println(result); // выведет "равно"
```

Вместо строк можно использовать другие выражения, например вызовы методов или объекты. В условии можно применять логические операторы.

**Пример с логическим оператором:**
```java
int a = 5;
String result = (a == 0 || a > 0) ? "неотрицательное" : "отрицательное";
System.out.println(result); // выведет "неотрицательное"
```
