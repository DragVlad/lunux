# Примитивные типы данных в Java

- в java 8 примитивных типов данных, они делятся на 4 группы;
- под каждую переменную сразу резервируется память;

  - целые числа:
    ```java
    byte number = 1; // 8 бит: диапазон -127 ... 127
    short number = 32.767 ; // 16 бит: диапазон -32.768 ... 32.767
    int number = 2_000_000; // 32 бит: -2ккк +2ккк - база
    long number = 2_000_000_000_000_000L; // 64 бит: оч много
    ```
  - вещественные числа:
  ```java
  float number = 1.1f; // 32 бит: - (7 цифр после запятой)
  double number = 1.2d; // 64 бит: - (15 цифр после запятой) - база
  ```
  - символьный тип
  ```java
  char z = 122; // номер символа в Unicode
  char a = 'a'; // одинарные кавычки обязательно
  ```
  - логический тип
  ```java
  // хорошая практика называть такие переменные с is
  boolean isLive = true;
  boolean isDead = false;
  ```

- В примитивных типах данных есть значение по умолчанию:
```java
byte/short/int -> 0
long -> 0L
float -> 0.0f // f - всегда обязателльно добавляется
double -> 0.0d
char -> '\u0000'
boolean -> false
ссылочные типы -> null
```
