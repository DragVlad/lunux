# Первоначальная настройка

- Обновляем пакеты + ядро
```bash
sudo apt update && sudo apt upgrade -y
```

- Устанавливаем и включаем ssh сервер(если его нет)
```bash
sudo apt install openssh-server -y
sudo systemctl enable ssh --now
```

- Настраиваем .ssh/config на локальной машине(ip-port-user)
- Копируем ssh ключ с ПК клиента(чтобы заходить по ssh)
```bash
ssh-copy-id user@ip_address
```
- Настраиваем `/etc/ssh/sshd_config` на сервере
```bash
sudo vi /etc/ssh/sshd_config
# Меняем порт (больше чем 12000)
# PermitRootLogin no - отключение входа root
# PubkeyAuthentication yes - аунтификация по ssh
#PasswordAuthentication no - отключение входа по паролю
```

- Отключаем ssh.socket и перезагружаем sshd
```bash
systemctl disable ssh.socket --now
systemctl restart sshd
ss -antlp # проверяем открытые порты
```

- Проверяем с какого ip мы подключались по ssh и разрешаем только его:
```bash
grep "Accepted" /var/log/auth.log
w
```

- Разрешаем вход по ssh Только с нужного IP
```bash
iptables -P INPUT DROP
iptables -A INPUT -p tcp --dport 18654 -s 192.168.0.13 -j ACCEPT

sudo apt install iptables-persistent -y
sudo netfilter-persistent save
```

- Установить штуки для кибербезы
```bash
sudo apt update
sudo apt install fail2ban
sudo systemctl start fail2ban
sudo systemctl enable fail2ban  # автозапуск при загрузке
sudo systemctl status fail2ban  # должен быть "active (running)"

wget https://github.com/aquasecurity/trivy/releases/download/v0.70.0/trivy_0.70.0_Linux-64bit.deb
sudo dpkg -i trivy_0.70.0_Linux-64bit.deb
trivy --version

# Сканирование файловой системы на высокие и критические уязвимости
trivy fs --scanners vuln --severity HIGH,CRITICAL /
trivy fs --scanners vuln --severity HIGH,CRITICAL / | grep Total
```
