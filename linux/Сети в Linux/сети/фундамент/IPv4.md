# Конспект: IPv4 адресация

## 1. Структура IPv4 адреса

### Основные характеристики
- **Длина:** 32 бита
- **Представление:** 4 октета (по 8 бит каждый)
- **Десятичная запись:** числа от 0 до 255, разделённые точками

### Пример преобразования
```
01010000 . 01001110 . 11111010 . 00010000
   80    .    78    .    250   .    16

80.78.250.16
```

## 2. Формат заголовка IPv4

```
 0                   8                  16                  31
|-------|-------|-------|-------|-------|-------|-------|-------|
|Version|  IHL  |  TOS  |        Total length                  |
|-------|-------|-------|-------|-------|-------|-------|-------|
|         Identification          |Flags|    Fragment offset    |
|-------|-------|-------|-------|-------|-------|-------|-------|
|  TTL   |Protocol|       Header checksum                      |
|-------|-------|-------|-------|-------|-------|-------|-------|
|                     Source address                           |
|-------|-------|-------|-------|-------|-------|-------|-------|
|                   Destination address                        |
|-------|-------|-------|-------|-------|-------|-------|-------|
|                     Options (0-40 bytes)                     |
|-------|-------|-------|-------|-------|-------|-------|-------|
|                         Data (до 65536 байт)                  |
```

### Поля заголовка
| Поле | Назначение |
|------|------------|
| **Version** | Версия IP (для IPv4 = 4) |
| **IHL** | Длина заголовка (Internet Header Length) |
| **TOS** | Тип сервиса (Type of Service) |
| **Total length** | Общая длина пакета (заголовок + данные) |
| **Identification** | Идентификатор для фрагментации |
| **Flags** | Флаги фрагментации |
| **Fragment offset** | Смещение фрагмента |
| **TTL** | Time To Live — время жизни пакета |
| **Protocol** | Протокол транспортного уровня (TCP=6, UDP=17, ICMP=1) |
| **Header checksum** | Контрольная сумма заголовка |
| **Source address** | IP-адрес отправителя |
| **Destination address** | IP-адрес получателя |
| **Options** | Опциональные поля (от 0 до 40 байт) |

## 3. Типы IP-адресов

### Публичные и частные («Белые» и «Серые»)

| Тип | Название | Маршрутизация в интернете | Кто назначает | Примеры |
|-----|----------|--------------------------|---------------|---------|
| **Публичные («Белые»)** | Public IP | Да | Региональные регистраторы (RIPE, ARIN и др.) | Любые, кроме зарезервированных |
| **Частные («Серые»)** | Private IP | Нет | Можно выбрать самостоятельно | 192.168.1.1 |

### Диапазоны частных («серых») адресов

| Класс | Диапазон | Маска (CIDR) | Количество адресов |
|-------|----------|--------------|-------------------|
| **A** | 10.0.0.0 — 10.255.255.255 | /8 | 16,777,216 |
| **B** | 172.16.0.0 — 172.31.255.255 | /12 | 1,048,576 |
| **C** | 192.168.0.0 — 192.168.255.255 | /16 | 65,536 |

> 📖 **RFC 6890** — полный список специальных диапазонов:  
> https://www.rfc-editor.org/rfc/rfc6890

---

## 4. Специальные адреса

| Диапазон | Назначение | Описание |
|----------|-----------|----------|
| **127.0.0.0 — 127.255.255.255** | Loopback | «Петля на себя» — адрес локального хоста (обычно 127.0.0.1) |
| **169.254.0.0 — 169.254.255.255** | APIPA | Automatic Private IP Addressing — когда DHCP недоступен (Windows) |
| **224.0.0.0 — 239.255.255.255** | Multicast | Групповая рассылка |

---

## 5. Типы передачи (адресация)

| Тип | Описание | Пример | Механизм |
|-----|----------|--------|----------|
| **Unicast** | Один отправитель → один получатель | 192.168.1.1/28 | Назначается одному интерфейсу |
| **Broadcast** | Один отправитель → все в сети | 192.168.1.255/24 | Последний адрес подсети |
| **Multicast** | Один → группа получателей | 224.0.0.0 — 239.255.255.255 | Групповая рассылка |
| **Anycast** | Один → ближайший из группы | (специальные диапазоны) | Один адрес у многих серверов |

### Пример на схеме
```
Unicast:    A ──────► B
Broadcast:  A ──────► B, C, D (всем в подсети)
Multicast:  A ──────► B, D (только подписанным)
Anycast:    A ──────► B (ближайшему из группы)
```

## 6. Основные выводы

### IP-адрес — это:
- ✅ Уникальный идентификатор **хоста** (точнее **интерфейса в подсети**)
- ✅ Указывается в пакете как **источник** (Source) и как **получатель** (Destination)
- ✅ Состоит из **32 бит**, обозначается в десятичной системе

### Где используются:
| Тип адресов | Где применяются |
|-------------|-----------------|
| **Публичные («Белые»)** | В сети Интернет |
| **Частные («Серые»)** | В локальных сетях (LAN) |

## 7. Практические команды для работы с IPv4

### Linux / macOS
```bash
# Просмотр IP-адресов интерфейсов
ip addr show
# или устаревшая команда
ifconfig -a

# Добавление IP-адреса интерфейсу
sudo ip addr add 192.168.1.10/24 dev eth0

# Удаление IP-адреса
sudo ip addr del 192.168.1.10/24 dev eth0
```

### Определение своего публичного IP
```bash
# Через утилиты
curl ifconfig.me
curl 2ip.ru
curl ipinfo.io/ip
```
