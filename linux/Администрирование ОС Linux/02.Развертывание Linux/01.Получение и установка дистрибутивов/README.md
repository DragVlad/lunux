# Установка Linux: от инсталлятора до ручной сборки

> **Инсталлятор** — это набор скриптов и утилит, объединённых графическим или псевдографическим интерфейсом, автоматизирующих пошаговую установку в виде диалога.

## Этап первый: получение дистрибутивов

В качестве примеров возьмём представителей двух самых популярных семейств:

| Дистрибутив | Семейство | Размер | Ссылка |
|-------------|-----------|--------|--------|
| **Fedora Server 40** (Network Install) | RedHat | ~775 Мб | [Скачать](https://download.fedoraproject.org/pub/fedora/linux/releases/40/Server/x86_64/iso/Fedora-Server-netinst-x86_64-40-1.14.iso) |

## Этап второй: установка через инсталлятор (Ubuntu / Fedora)

### 1. Создание виртуальной машины в VirtualBox

**Базовые настройки для обеих ВМ:**

- **Имя:** Ubuntu / Fedora
- **Тип:** Linux
- **Версия:** Redhat 64 bit
- **Образ ISO:** указать путь к скачанному файлу
- **Отметить:** «Пропустить автоматическую установку»

### 2. Настройка оборудования

| Параметр | Значение |
|----------|----------|
| Оперативная память | 2 ГБ |
| Процессор | 1 ядро |
| Виртуальный диск | 50 Гб (динамический) |

> [!note]
> Чудеса виртуализации: диск ВМ растёт по мере заполнения данными, хотя ВМ «думает», что всё место доступно сразу.

### 3. Настройка сети (опционально)

- Адаптер 1 → тип подключения: **Сетевой мост**
- Подключить к вашему сетевому адаптеру (проводному или Wi-Fi)

### 4. Порядок загрузки

В настройках системы установить загрузку с **оптического привода (ISO)** в первую очередь.

### 5. Запуск установки

При загрузке выбрать:
- **Fedora:** `Try or Install`
- **Ubuntu:** `Install`

Язык можно выбрать любой (в примере — English).

## Установка дистрибутива без инсталлятора (Arch Linux)

Использованные ранее дистрибутивы (Ubuntu, Fedora) — **бинарные**. Они скрывают от нас часть реальности. Альтернатива — дистрибутивы, поставляемые в виде исходных кодов (Gentoo, Linux From Scratch), но они очень трудоёмки.

> **Arch Linux** — золотая середина: компоненты уже собраны, но инсталлятор отсутствует. Пользователь сам проводит установку и настройку, получая полный контроль.

### 1. Загрузка образа

Скачайте ISO с [официального сайта](https://archlinux.org/download/), например: `archlinux-2024.06.01-x86_64.iso`. Создайте новую ВМ аналогично предыдущим.

### 2. Следование инструкции

Основной ориентир — [официальное руководство по установке](https://wiki.archlinux.org/title/installation_guide).

#### Настройка сети (ручная)

```bash
# Посмотреть назначенный адрес
ip a

# Удалить старый адрес и назначить вручную
ip addr del <старый_адрес>/24 dev ens3
ip addr add 192.168.1.100/24 dev ens3

# Настроить маршрут по умолчанию
ip route add default via 192.168.1.1

# Настроить DNS (в файле /etc/resolv.conf)
echo "nameserver 8.8.8.8" > /etc/resolv.conf
```

#### Разметка диска (с помощью cfdisk)

```bash
cfdisk /dev/sda
```

Создаём 4 раздела:

| Раздел | Размер | Назначение |
|--------|--------|------------|
| `/dev/sda1` | 5 Гб | `/boot` |
| `/dev/sda2` | 30 Гб | `/` (корень) |
| `/dev/sda3` | 5 Гб | `/home` |
| `/dev/sda4` | 10 Гб | `/var/log` |

После разметки: **Write** → **Quit**.

#### Создание файловых систем (ext4)

```bash
mkfs.ext4 /dev/sda1
mkfs.ext4 /dev/sda2
mkfs.ext4 /dev/sda3
mkfs.ext4 /dev/sda4
```

#### Монтирование разделов

```bash
mount /dev/sda2 /mnt
mkdir /mnt/boot /mnt/home /mnt/var/log
mount /dev/sda1 /mnt/boot
mount /dev/sda3 /mnt/home
mount /dev/sda4 /mnt/var/log
```

#### Установка базовых пакетов

```bash
pacstrap -K /mnt base linux linux-firmware vim grub parted
```

#### Генерация fstab

```bash
genfstab -U /mnt >> /mnt/etc/fstab
```

#### Вход в новую систему (chroot)

```bash
arch-chroot /mnt
```

#### Настройка времени

```bash
ln -sf /usr/share/zoneinfo/Europe/Moscow /etc/localtime
hwclock --systohc
```

#### Настройка локалей

```bash
vim /etc/locale.gen
# Раскомментировать: en_US.UTF-8 UTF-8

locale-gen

echo "LANG=en_US.UTF-8" > /etc/locale.conf
```

#### Настройка имени хоста и пароля root

```bash
echo "myarch" > /etc/hostname
passwd   # пароль не отображается при вводе
```

#### Установка загрузчика GRUB

```bash
grub-install /dev/sda   # именно устройство, а не раздел!
grub-mkconfig -o /boot/grub/grub.cfg
```

#### Завершение

```bash
exit           # выход из chroot
reboot         # перезагрузка
```

## Итог

Мы рассмотрели три варианта установки Linux:

1. **Ubuntu Server** — классический инсталлятор с пошаговым диалогом
2. **Fedora Server** — инсталлятор с графическим интерфейсом (Anaconda)
3. **Arch Linux** — ручная установка, дающая полный контроль над системой

> [!tip]
> Arch Linux идеально подходит для понимания того, что «под капотом» у привычных дистрибутивов. Но для повседневной серверной работы Ubuntu и Fedora — более практичный выбор.
