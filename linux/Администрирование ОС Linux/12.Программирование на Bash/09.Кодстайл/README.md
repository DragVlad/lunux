# Кодстайл и лучшие практики

**Ссылки на руководства по стилю:**

- [Google Shell Style Guide](https://google.github.io/styleguide/shellguide.html)
- [Bahamas10's Bash Style Guide](https://github.com/bahamas10/bash-style-guide)
- [Icy's Bash Coding Style](https://github.com/icy/bash-coding-style)

Этот стайлгайд создан на основе рекомендаций из различных руководств по стилю написания Bash-скриптов, включая Google Shell Style Guide, Bahamas10's Bash Style Guide и Icy's Bash Coding Style. Он содержит важнейшие моменты для обеспечения высококачественного, читаемого и поддерживаемого кода.

## Форматирование и структура кода

### Отступы и пробелы

- Используйте 2 пробела для отступов. Не используйте табуляцию, чтобы обеспечить согласованное форматирование.
- Разделяйте логические блоки кода пустыми строками для лучшей читаемости.

```bash
if [ "$var" -eq 1 ]; then
  echo "Variable is 1"
else
  echo "Variable is not 1"
fi
```

- Добавляйте пробелы вокруг операторов и в логических выражениях:

```bash
count=$(( a + b ))
```

### Закрытие блоков

- Разделяйте операторы `if`, `for`, `while` и их закрывающие команды (`fi`, `done`) вертикально.
- `then` и `do` должны находиться на той же строке, что и соответствующая управляющая конструкция.

```bash
if [ "$var" -eq 1 ]; then
  echo "Variable is 1"
else
  echo "Variable is not 1"
fi
```

### Организация кода в логические блоки

Включите разделы для переменных, функций и основного блока выполнения.

```bash
# Переменные
user_name="Alice"

# Функции
function greet() {
  echo "Hello, $user_name"
}

# Основной блок
greet
```

### Использование main функции для входной точки

Это делает код более читаемым и управляемым:

```bash
function main() {
  greet
  calculate_sum 5 10
}

main "$@"
```

## Именование переменных и функций

### Переменные

Используйте `snake_case` для локальных переменных. Для глобальных переменных и констант используйте **заглавные буквы** с подчеркиваниями.

```bash
readonly MAX_RETRIES=5
file_name="example.txt"
```

### Функции

Имена функций также должны быть в `snake_case`. Используйте глаголы, чтобы обозначить действие, выполняемое функцией.

```bash
process_file() {
  local file_name="$1"
  echo "Processing $file_name"
}
```

### Читаемые имена

Правильное именование переменных и функций делает код более читаемым и понятным.

**Переменные:** используйте имена, которые описывают назначение переменной:

```bash
user_name="Alice"
total_amount=100
```

**Функции:** имя функции должно отражать действие, которое она выполняет:

```bash
function calculate_sum() { ... }
function print_report() { ... }
```

## Экранирование переменных и использование скобок

Всегда оформляйте переменные фигурными скобками, чтобы избежать проблем с разбиением по пробелам или спецсимволами. Используйте `"${var}"` вместо `$var`.

```bash
echo "Значение переменной: ${my_var}"
```

## Функции и область видимости переменных

### Использование local

Объявляйте переменные внутри функций с помощью ключевого слова `local`, чтобы избежать загрязнения глобального пространства.

```bash
process_file() {
  local temp_file="/tmp/output.txt"
  echo "Working with $temp_file"
}
```

### Массивы

Используйте массивы для работы с наборами данных, таких как флаги командной строки.

```bash
declare -a files=("file1.txt" "file2.txt")
for file in "${files[@]}"; do
  echo "Processing $file"
done
```

## Управляющие конструкции

### Управление потоками

Используйте явные блоки `if`, `for`, `while`, чтобы улучшить читаемость. Избегайте компактных однострочных конструкций.

```bash
for file in "${files[@]}"; do
  if [[ -f "$file" ]]; then
    echo "Processing $file"
  else
    echo "File not found"
  fi
done
```

### case конструкции

Разделяйте условия в `case` и альтернативы вертикально, с правильным отступом для лучшей читаемости.

```bash
case "$1" in
  start)
    echo "Starting service"
    ;;
  stop)
    echo "Stopping service"
    ;;
  *)
    echo "Unknown option"
    exit 1
    ;;
esac
```

## Проверка возвратов и ошибок

### Проверка статуса команды

Всегда проверяйте возвращаемый статус команд через переменную `$?` для обработки ошибок.

```bash
if ! cp file.txt /backup/; then
  echo "Ошибка при копировании файла" >&2
  exit 1
fi
```

### Использование set -e

Используйте `set -e` для автоматического завершения скрипта при ошибках команд.

## Аргументы командной строки

### Использование getopts для флагов

Для работы с опциями командной строки используйте `getopts`.

```bash
while getopts "abf:" opt; do
  case $opt in
    a) aflag=true ;;
    b) bflag=true ;;
    f) file="$OPTARG" ;;
    *) echo "Invalid option" ;;
  esac
done
```

### Использование $@ для аргументов

Для передачи всех аргументов командной строки используйте `"${@}"` вместо `$*`, чтобы сохранить аргументы целыми.

## Инструменты для отладки

### Использование set -x для отладки

Включайте `set -x` для вывода выполнения команд в отладочных режимах.

```bash
set -x
cp file.txt /backup/
set +x
```

### ShellCheck

Регулярно проверяйте скрипты через [ShellCheck](https://www.shellcheck.net/) для выявления ошибок.

## Другие полезные практики

### Комментирование

Всегда используйте комментарии для пояснения сложных участков кода или важной логики.

```bash
# Проверка доступности файла перед копированием
if [[ -f "$file" ]]; then
  cp "$file" /backup/
fi
```

### Работа с подстановками команд

Используйте `$(command)` вместо обратных апострофов (`` `command` ``), поскольку это более читаемый и современный способ подстановки команд.

```bash
output=$(ls -l)
```
