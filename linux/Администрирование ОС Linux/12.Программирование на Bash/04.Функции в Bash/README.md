# Функции в Bash

## Зачем нужны функции

> Функции в Bash, как и в других языках программирования, позволяют структурировать код, улучшая его читаемость и повторное использование. С их помощью можно выделить часто используемые блоки кода, уменьшить количество дублирующихся команд и сделать скрипт более управляемым.

**Основные причины для использования функций:**

- **Повторное использование кода**: функции можно вызвать многократно, что экономит время и уменьшает вероятность ошибок.
- **Чистота и читаемость**: разделение кода на функции улучшает его читаемость и упрощает сопровождение.
- **Инкапсуляция логики**: функции позволяют скрыть сложные детали реализации, предоставляя простой интерфейс.

## Обязательные элементы функций

Функция в Bash состоит из имени, тела функции и опциональных параметров. Имя функции должно быть **уникальным в рамках скрипта**.

| Описание | Пример |
|----------|--------|
| **Объявление функции** | `function function_name() { тело функции }` |
| **Пример функции** | `function greet() { local name=$1; echo "Hello, $name!"; }; greet "Bob"` |
| **Параметры функции** — передаются как аргументы и доступны через `$1`, `$2` и так далее | `function add() { local sum=$(( $1 + $2 )); echo "Sum: $sum"; }; add 5 10` |
| **Возврат числовых значений** через `return` | `function multiply() { local product=$(( $1 * $2 )); return $product; }; multiply 3 4; echo "Product: $?"` |
| **Возврат строки** через `echo` | `function get_name() { echo "Alice"; }; name=$(get_name); echo "Name: $name"` |

## Использование глобальных и локальных переменных

> В Bash переменные могут быть глобальными или локальными, в зависимости от области видимости и контекста, в котором они используются. Это важно для управления данными в скриптах, особенно при работе с функциями.

### Глобальные переменные

Глобальные переменные доступны во всём скрипте, включая все функции и вложенные сценарии. Если переменная объявлена вне функции, она считается глобальной и может быть доступна из любого места в скрипте.

```bash
#!/bin/bash

my_var="Глобальная переменная"

my_function() {
    echo "Из функции: $my_var"
}

echo "Вне функции: $my_var"
my_function
```

### Локальные переменные

Локальные переменные объявляются внутри функции с помощью ключевого слова `local` и доступны только в пределах этой функции. Они не влияют на одноимённые глобальные переменные за пределами функции.

```bash
#!/bin/bash

my_var="Глобальная переменная"

my_function() {
    local my_var="Локальная переменная"
    echo "Из функции: $my_var"
}

echo "Вне функции (до вызова функции): $my_var"
my_function
echo "Вне функции (после вызова функции): $my_var"
```

### Важные моменты

1. **Область видимости глобальных переменных**: глобальные переменные могут быть использованы в любом месте скрипта, включая функции, если в этих функциях нет переменных с таким же именем, объявленных как локальные.

2. **Область видимости локальных переменных**: локальные переменные существуют только внутри функции, в которой они объявлены. После завершения функции эти переменные исчезают, и их значение недоступно за пределами функции.

> **Если локальная переменная имеет то же имя, что и глобальная, локальная переменная будет «скрывать» глобальную переменную внутри функции.**

```bash
#!/bin/bash

my_var="Глобальная переменная"

my_function() {
    local my_var="Локальная переменная"
    echo "Из функции: $my_var"
}

echo "До вызова функции: $my_var"
my_function
echo "После вызова функции: $my_var"
```

### Наследование переменных в дочерних процессах

Когда Bash-сценарий или функция запускает другой процесс (например, выполняет другой скрипт или команду), глобальные переменные могут быть унаследованы, но **локальные переменные** доступны только в том процессе, в котором они были объявлены.

### Когда использовать локальные и глобальные переменные

- **Локальные переменные** следует использовать внутри функций, чтобы избежать конфликтов имён и случайного изменения глобальных переменных. Это особенно полезно, когда функции вызываются из разных частей скрипта, и важно, чтобы их переменные не влияли на другие части программы.

- **Глобальные переменные** можно использовать для данных, которые нужны во всём скрипте или которые должны передаваться между функциями. Однако чрезмерное использование глобальных переменных может привести к трудностям в отладке и непредсказуемым ошибкам.
