# Sed, AWK и альтернативы

## sed — Stream Editor

> `sed` — это потоковый редактор, который применяется для обработки текста построчно. Он может модифицировать текст в реальном времени без необходимости редактировать исходный файл.

**Основные возможности sed:**

- Поиск и замена текста
- Удаление строк
- Извлечение строк по паттернам
- Вставка текста в определенные строки

**Пример 1: простая замена текста**

```bash
echo "Привет, мир!" | sed 's/мир/вселенная/'
```

**Пример 2: замена текста в файле**

```bash
sed -i 's/старый_текст/новый_текст/g' файл.txt
```

Флаг `-i` используется для изменения файла на месте. `g` в конце шаблона замены указывает, что замена должна быть выполнена для всех вхождений в строке.

**Пример 3: удаление строк**

```bash
sed '/удалить_эту_строку/d' файл.txt
```

Удаляет все строки, содержащие шаблон «удалить_эту_строку».

**Пример 4: вставка строки после определенной строки**

```bash
sed '/найти_это/a Вставить эту строку' файл.txt
```

Команда `a` добавляет новую строку после строки, соответствующей шаблону «найти_это».

## awk — Text Processing Utility

> `awk` — это язык программирования, предназначенный для обработки текстовых данных и работы с табличными данными. Он позволяет выполнять сложные операции с текстом, включая фильтрацию строк, разделение полей, математические операции и форматирование вывода.

**Основные возможности awk:**

- Разделение строк на поля
- Применение арифметических операций к данным
- Форматирование вывода
- Поддержка условных выражений и циклов

**Пример 1: печать второго поля**

```bash
echo "Имя Фамилия Возраст" | awk '{print $2}'
```

Здесь `awk '{print $2}'` выводит второе поле строки, разделённой пробелом.

**Пример 2: подсчёт значений в колонках**

```bash
awk '{sum += $2} END {print "Сумма:", sum}' данные.txt
```

Этот скрипт суммирует все значения во второй колонке файла `данные.txt`.

**Пример 3: условная фильтрация**

```bash
awk '$3 > 30 {print $1, $2}' данные.txt
```

Выводит первые два поля только тех строк, где третье поле больше 30.

**Пример 4: форматированный вывод**

```bash
awk '{printf "Имя: %s, Возраст: %d\n", $1, $2}' данные.txt
```

Форматирует вывод с помощью функции `printf`.

## Альтернативы sed и awk

### cut

`cut` используется для извлечения определенных полей или символов из строк.

**Пример использования cut:**

```bash
echo "Имя Фамилия Возраст" | cut -d ' ' -f 2
```

Здесь `cut` извлекает второе поле, используя пробел в качестве разделителя (`-d ' '`).

**Извлечение первых двух полей из CSV:**

```bash
cut -d ',' -f 1,2 файл.csv
```

### tr

`tr` заменяет или удаляет символы из потока текста.

**Пример использования tr (преобразование в верхний регистр):**

```bash
echo "Привет, Мир!" | tr '[:lower:]' '[:upper:]'
```

**Удаление символов:**

```bash
echo "Привет, Мир!" | tr -d ','
```

Удаляет запятые.

### jq

> `jq` — это мощная утилита для обработки JSON-файлов, которая предоставляет функции для фильтрации, преобразования и форматирования JSON-данных.

**Пример обработки JSON с помощью jq (извлечение поля):**

```bash
echo '{"имя": "Иван", "возраст": 30}' | jq '.имя'
```

`jq` используется для извлечения поля "имя" из JSON-объекта.

**Фильтрация массива JSON:**

```bash
jq '.[] | select(.возраст > 25)' файл.json
```

Этот пример выводит все объекты из массива JSON, у которых значение поля «возраст» больше 25.
