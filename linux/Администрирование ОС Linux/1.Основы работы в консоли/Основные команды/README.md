# Основные команды Linux

Изучение основных команд Linux для новичка является важным шагом для понимания и эффективного использования системы. Давайте посмотрим на некоторый базовый набор команд, сгруппировав их логически по категориям, чтобы было проще запомнить и изучать.

---

## Навигация и перемещение по файловой системе

| Команда | Описание | Пример |
|---------|----------|--------|
| `ls` | От слова *list* — вывести список файлов в текущем каталоге. Просто так или с доп. информацией об их атрибутах | `ls` — показать список файлов<br>`ls -l` — расширенный формат (права, владелец)<br>`ls -a` — показать скрытые файлы |
| `cd` | *Change directory* — сменить каталог. Без аргументов возвращает в домашний каталог | `cd /path/to/dir`<br>`cd ..` — на уровень выше<br>`cd ~` — в домашний каталог |
| `pwd` | *Print working directory* — вывести текущий (рабочий) каталог | `pwd` |

---

## Работа с файлами и каталогами

| Команда | Описание | Пример |
|---------|----------|--------|
| `mkdir` | *Make directory* — создать каталог | `mkdir new_dir`<br>`mkdir -p path/to/dir` — создать каталог и весь путь до него |
| `rmdir` | *Remove directory* — удалить **только пустой** каталог | `rmdir empty_dir` |
| `rm` | *Remove* — удалить файлы и каталоги. **Самая опасная команда** | `rm file`<br>`rm -r directory` — рекурсивно<br>`rm -rf path` — **крайне опасно!** |
| `cp` | *Copy* — копировать файлы и папки | `cp source dest`<br>`cp -r source_dir dest_dir` |
| `mv` | *Move* — переместить файл или каталог | `mv old_name new_name`<br>`mv file /path/to/dest/` |
| `touch` | «Потрогать» файл: если нет — создать, если есть — обновить время доступа | `touch file.txt` |
| `cat` | *Concatenate* — вывести содержимое файла | `cat file.txt`<br>`cat file1 file2` |
| `less` | Постраничное чтение файлов. Удобно для логов и длинных файлов | `less file.txt`<br>`/string` — поиск вниз<br>`q` — выход |
| `head` | Вывести начало файла (по умолчанию 10 строк) | `head file.txt`<br>`head -n 20 file.txt` |
| `tail` | Вывести конец файла (по умолчанию 10 строк) | `tail file.txt`<br>`tail -f file.txt` — следить за логом в реальном времени |
| `echo` | Вывести строку текста | `echo "Hello, World!"`<br>`echo -n "no newline"` |

> [!tip]
> Команда `rm -rf` удаляет всё безвозвратно и без подтверждения. **Будьте предельно осторожны!**

## Поиск

| Команда | Описание | Пример |
|---------|----------|--------|
| `grep` | Искать подстроку или регулярное выражение в файле или потоке | `grep "text" file.txt`<br>`grep -i "TEXT" file` — без учёта регистра<br>`grep -r "text" /path/` — рекурсивно |
| `find` | Поиск файлов и директорий | `find /path -name "filename"` |

## CLI веб-клиенты

| Команда | Описание | Пример |
|---------|----------|--------|
| `curl` | Веб-клиент для взаимодействия с ресурсами по URL | `curl https://example.com`<br>`curl -o file url` — сохранить файл<br>`curl -I url` — показать заголовки |
| `wget` | Загрузка файлов по HTTP(S) и FTP | `wget https://example.com/file`<br>`wget -P /save/path url` |

## Получение справки

| Команда | Описание | Пример |
|---------|----------|--------|
| `man` | *Manual* — полная документация по любой команде. **Самая главная команда в Linux** | `man man` — справка о справке<br>`man ls` |
| `--help` | Краткая справка по команде | `ls --help` |

> [!note]
> **`man`** — ваш лучший друг в Linux. Любая команда, любой конфигурационный файл — всё описанно в руководствах. Учитесь читать `man` — и вы освоите любую утилиту.
