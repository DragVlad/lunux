# Алиасы (псевдонимы команд) в Linux

> Алиасы (alias) в Linux — это псевдонимы для команд или их комбинаций, которые позволяют упростить и ускорить работу с командной строкой. С помощью алиасов можно создать короткие и запоминающиеся команды для часто используемых длинных или сложных конструкций.

Проще говоря, это способ **существенно упростить себе жизнь**, спрятав под коротким именем целые однострочные скрипты с параметрами.

---

## Создание временного алиаса

Алиасы, созданные таким образом, **действуют только в текущей сессии терминала**:

```bash
alias короткое_имя='длинная команда'

alias ll='ls -l'
alias gs='git status'
```

---

## Удаление алиаса

Чтобы удалить алиас, используйте команду `unalias`:

```bash
unalias короткое_имя
```

---

## Постоянные алиасы

> [!important]
> Чтобы алиасы сохранялись между сессиями, их нужно добавить в файл конфигурации оболочки.

Для `bash` это обычно файл `~/.bashrc` или `~/.bash_aliases`, а для `zsh` — `~/.zshrc`.

### Пошаговая инструкция

1. **Откройте файл конфигурации** в текстовом редакторе:

```bash
nano ~/.bashrc
```

2. **Добавьте алиасы** в конец файла:

```bash
alias ll='ls -l'
alias gs='git status'
```

3. **Сохраните** и закройте редактор.

4. **Перезагрузите конфигурацию**:

```bash
source ~/.bashrc
```

> [!tip]
> Можно также просто открыть новый терминал — файлы конфигурации загрузятся автоматически.

## Примеры полезных алиасов

| Алиас | Описание |
|-------|----------|
| `alias ll='ls -lh'` | Просмотр подробного списка файлов в человекочитаемом формате |
| `alias lt='ls -lt'` | Список файлов с сортировкой по времени изменения |
| `alias rm='rm -i'` | Запрашивать подтверждение при удалении файлов |
| `alias update='sudo apt update && sudo apt upgrade'` | Быстрое обновление пакетов для Debian/Ubuntu |
