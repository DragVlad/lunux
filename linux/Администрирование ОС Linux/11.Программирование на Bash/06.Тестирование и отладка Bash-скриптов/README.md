# Тестирование и отладка Bash-скриптов

> Отладка Bash-скриптов — важный процесс, который помогает найти и исправить ошибки в коде. В Bash есть встроенные инструменты и техники, которые позволяют отслеживать выполнение скрипта, просматривать вывод переменных, получать информацию об ошибках и управлять логикой выполнения программы.

## Включение режима отладки

В Bash есть несколько встроенных опций, которые можно использовать для отладки скриптов. Эти опции помогают отслеживать выполнение команд, выводить отладочную информацию и проверять ошибки.

### Опция -x — вывод выполнения команд

При использовании флага `-x` Bash выводит каждую команду перед её выполнением. Это помогает увидеть, какие команды выполняются и в каком порядке.

**Способы включения режима отладки:**

| Способ | Пример |
|--------|--------|
| Запуск скрипта с флагом `-x` | `bash -x script.sh` |
| Добавление опции `-x` в начале скрипта | `#!/bin/bash -x` |
| Включение режима отладки внутри скрипта | `set -x` (включить), `set +x` (отключить) |

**Пример включения отладки внутри скрипта:**

```bash
# Включаем отладку
set -x
echo "Эта команда будет показана в отладочном выводе"
# Отключаем отладку
set +x
echo "Эта команда не будет показана"
```

### Опция -v — вывод исходного текста команд

Опция `-v` выводит текст команд перед их выполнением. В отличие от `-x`, выводится исходный код команд без подстановки значений переменных.

| Способ | Пример |
|--------|--------|
| Запуск скрипта с флагом `-v` | `bash -v script.sh` |
| Добавление опции `-v` в начале скрипта | `#!/bin/bash -v` |
| Включение режима отладки внутри скрипта | `set -v` (включить), `set +v` (отключить) |

### Совмещение -x и -v

Можно использовать оба флага вместе, чтобы одновременно видеть исходный код команд и результат их выполнения:

```bash
bash -xv script.sh
```

## Использование trap для отладки

Команда `trap` позволяет захватывать сигналы и выполнять команды при их получении. Это полезно для отладки и отслеживания того, когда скрипт завершился или произошла ошибка.

### Отслеживание выхода скрипта

Этот скрипт выполнит команду `trap`, когда произойдёт завершение скрипта, и выведет код завершения:

```bash
#!/bin/bash

trap 'echo "Скрипт завершился. Код выхода: $?"' EXIT

echo "Работаем..."
sleep 2
```

### Отладка ошибок с trap

Здесь `trap` перехватывает ошибку (ERR) и выводит номер строки (`$LINENO`), в которой произошла ошибка, а также код ошибки (`$?`):

```bash
#!/bin/bash

trap 'echo "Ошибка в строке $LINENO. Код выхода: $?"' ERR

echo "Начинаем работу"

# Эта команда вызовет ошибку
cp non_existent_file.txt destination.txt
```

## Отладочный вывод через echo или printf

> Использование команд `echo` и `printf` — это простой и популярный метод для отладки скриптов. Вывод значений переменных и результатов команд помогает понять, что происходит в процессе выполнения.

```bash
#!/bin/bash

name="Иван"
echo "Значение переменной name: $name"

if [ -z "$name" ]; then
    echo "Переменная name пуста"
else
    echo "Переменная name не пуста"
fi
```

Можно вставлять команды `echo` в ключевые места кода, чтобы отслеживать выполнение скрипта и значения переменных на каждом шаге.

## Проверка кода завершения команд

После каждой команды в Bash есть возможность проверить её код завершения, используя переменную `$?`. Если команда выполнена успешно, код завершения будет равен 0; если произошла ошибка — ненулевое значение.

```bash
#!/bin/bash

cp source.txt destination.txt
if [ $? -ne 0 ]; then
    echo "Ошибка при копировании файла"
fi
```

Это позволяет проверять успешность выполнения команд и выводить сообщение об ошибке при необходимости.

## Использование set -e для немедленного завершения при ошибке

Флаг `-e` заставляет Bash немедленно завершить выполнение скрипта, если любая команда завершится с ненулевым кодом.

```bash
#!/bin/bash
set -e

echo "Начало работы"
cp non_existent_file.txt destination.txt  # Ошибка остановит выполнение
echo "Эта строка не будет выполнена"
```

Когда команда завершится с ошибкой, скрипт немедленно завершится, и последующие команды не будут выполнены.

## shellcheck — анализатор Bash-скриптов

> `shellcheck` — это утилита для статического анализа Bash-скриптов. Она помогает находить синтаксические ошибки, проблемы с переменными, неправильное использование команд и другие ошибки.

**Установка shellcheck:**

```bash
sudo apt install shellcheck  # Для Ubuntu/Debian
sudo yum install shellcheck  # Для RHEL/CentOS
```

**Использование shellcheck:**

```bash
shellcheck script.sh
```

**Пример вывода:**

```text
In script.sh line 4:
name="Ivan"
^-- SC2034: name appears unused. Verify use (or export if used externally).
```

`shellcheck` анализирует скрипт и выводит рекомендации по исправлению ошибок и улучшению кода.

---

> Отладка Bash-скриптов включает в себя использование встроенных средств, таких как флаги `-x`, `-v`, команда `trap`, а также внешние утилиты, такие как `shellcheck`. Важно использовать различные методы отладки, чтобы упростить процесс поиска ошибок и повысить стабильность и читаемость скриптов.
