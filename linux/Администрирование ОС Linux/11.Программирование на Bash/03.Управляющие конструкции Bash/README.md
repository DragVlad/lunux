# Управляющие конструкции Bash

> Bash (Bourne Again Shell) предоставляет набор управляющих конструкций, которые позволяют управлять логикой выполнения скриптов, принимать решения, выполнять циклические действия и обрабатывать условия. Эти конструкции являются основными инструментами для построения логики программ в Bash.

Управляющие конструкции в Bash предоставляют мощные инструменты для контроля выполнения скриптов. Их правильное использование позволяет создавать эффективные, гибкие и хорошо структурированные скрипты, решающие различные задачи.

## Условная конструкция if-elif-else

> Конструкция *if-elif-else* в Bash — это основной инструмент для ветвления выполнения программы в зависимости от выполнения тех или иных условий. С её помощью можно проверять значения переменных, результаты выполнения команд и принимать решения на основе этих проверок.

**Синтаксис:**

```bash
if [ условие ]; then
    команды_если_истина
elif [ условие ]; then
    команды_если_второе_условие_истина
else
    команды_если_ложь
fi
```

**Важные моменты:**
- условия заключаются в квадратные скобки, и между скобками и условием должны быть пробелы
- после команды `then` должна быть новая строка или точка с запятой, если это делается на одной строке
- `elif` можно использовать несколько раз, если есть несколько альтернативных проверок

**Пример:**

```bash
#!/bin/bash
a=5
b=3

if [ $a -gt $b ]; then
    echo "$a больше $b"
elif [ $a -eq $b ]; then
    echo "$a равно $b"
else
    echo "$a меньше $b"
fi
```

### Операторы условий

| Тип | Операторы | Пример |
|-----|-----------|--------|
| **Числовые сравнения** | `-eq` (равно), `-ne` (не равно), `-gt` (больше), `-lt` (меньше), `-ge` (больше или равно), `-le` (меньше или равно) | `if [ $x -gt $y ]; then echo "$x больше $y"; fi` |
| **Строковые сравнения** | `=` (равны), `!=` (не равны), `-z` (строка пустая), `-n` (строка не пустая) | `if [ "$name" = "John" ]; then echo "Привет, Джон!"; fi` |
| **Проверка файлов** | `-e` (файл существует), `-f` (существует файл, не директория), `-d` (существует директория), `-r` (доступен для чтения), `-w` (доступен для записи), `-x` (доступен для выполнения) | `if [ -e "/path/to/file" ]; then echo "Файл существует"; fi` |
| **Логические операторы** | `&&` (логическое И), `||` (логическое ИЛИ) | `if [ $age -ge 18 ] && [ $age -le 30 ]; then echo "Вы в возрасте от 18 до 30 лет"; fi` |

**Особенности if-elif-else в Bash:**

1. **Возврат статуса команды**: любая команда в Bash возвращает статус завершения (0 для успеха, ненулевое для ошибки). Конструкция `if` основывается на этом статусе для проверки условий.

2. **Логические выражения в квадратных скобках**: для простых сравнений используется команда `test`, эквивалентная записи `[ условие ]`. Также можно использовать расширенные выражения с двойными скобками `[[ ]]`, которые поддерживают более сложные логические выражения и регулярные выражения.

## Цикл for

> Цикл *for* в Bash используется для многократного выполнения набора команд для каждого элемента из указанного списка значений, файлов или диапазона чисел. Это одна из основных управляющих конструкций, которая позволяет эффективно обрабатывать данные в скриптах.

**Синтаксис:**

```bash
for переменная in список_значений; do
    команды
done
```

### Варианты использования цикла for

| Описание | Пример |
|----------|--------|
| Перебор списка заранее заданных значений | `for fruit in apple banana cherry; do echo "Фрукт: $fruit"; done` |
| Обработка файлов в каталоге | `for file in /path/to/directory/*; do echo "Файл: $file"; done` |
| Перебор числовых диапазонов `{start..end}` | `for i in {1..5}; do echo "Число: $i"; done` |
| Перебор диапазона с шагом `{start..end..step}` | `for i in {0..10..2}; do echo "Число: $i"; done` |
| Перебор элементов массива | `for fruit in "${array[@]}"; do echo "Фрукт: $fruit"; done` |
| Использование результата команды как списка значений | `for file in $(ls /path/to/directory); do echo "Файл: $file"; done` |

## Цикл while

> Цикл *while* в Bash используется для выполнения набора команд до тех пор, пока условие остается истинным. Он выполняет команды в блоке цикла, проверяя условие перед каждой итерацией. Это делает `while` полезным для циклов с неизвестным заранее количеством итераций, где нужно выполнять команды до достижения какого-то события или условия.

**Синтаксис:**

```bash
while [ условие ]; do
    команды
done
```

### Примеры использования цикла while

| Описание | Пример |
|----------|--------|
| Простой цикл с арифметическим условием | `counter=1; while [ $counter -le 5 ]; do echo "Итерация $counter"; counter=$((counter + 1)); done` |
| Получение данных от пользователя до нужного значения | `password=""; while [ "$password" != "secret" ]; do read -sp "Введите пароль: " password; done; echo "Пароль верный!"` |
| Выполнение пока команда возвращает статус 0 | `while ping -c 1 google.com >/dev/null 2>&1; do echo "Google доступен"; sleep 1; done; echo "Google недоступен"` |
| Построчная обработка файла | `while IFS= read -r line; do echo "Строка: $line"; done < file.txt` |
| Комбинация с логическими операторами | `while [ $x -lt 10 ] && [ $y -gt 5 ]; do echo "x: $x, y: $y"; x=$((x + 1)); y=$((y - 1)); done` |

**Простой цикл:**

```bash
#!/bin/bash
count=1
while [ $count -le 5 ]; do
    echo "Count: $count"
    count=$((count + 1))
done
```

**Чтение строк из файла:**

```bash
#!/bin/bash
while read line; do
    echo "Line: $line"
done < filename.txt
```

## Цикл until

> Цикл *until* похож на цикл *while*, является его альтернативой. Но цикл *until* работает наоборот: команды выполняются до тех пор, пока условие ложно. Как только условие становится истинным, цикл завершается.

**Синтаксис:**

```bash
until [ условие ]; do
    команды
done
```

**Пример:**

```bash
#!/bin/bash
count=1
until [ $count -gt 5 ]; do
    echo "Count: $count"
    count=$((count + 1))
done
```

## Конструкция case

Конструкция *case* в Bash используется для создания многовариантного ветвления выполнения программы. Она особенно удобна, когда нужно проверить одно значение на соответствие нескольким возможным вариантам. В отличие от многочисленных проверок через if-elif-else, `case` позволяет сделать код более читабельным и легко управляемым.

**Синтаксис:**

```bash
case выражение in
    шаблон1)
        команды
        ;;
    шаблон2)
        команды
        ;;
    *)
        команды по умолчанию
        ;;
esac
```

**Пример:**

```bash
#!/bin/bash
echo "Введите число от 1 до 3:"
read num

case $num in
    1)
        echo "Вы ввели один"
        ;;
    2)
        echo "Вы ввели два"
        ;;
    3)
        echo "Вы ввели три"
        ;;
    *)
        echo "Некорректный ввод"
        ;;
esac
```

### Особенности конструкции case

| Особенность | Пример |
|-------------|--------|
| **Поддержка шаблонов**: `*` (любое количество символов), `?` (один символ), `[abc]` (один из символов в скобках) | `case $letter in [a-z]) echo "Маленькая буква";; [A-Z]) echo "Заглавная буква";; [0-9]) echo "Цифра";; *) echo "Неизвестный символ";; esac` |
| **Объединение нескольких шаблонов** через `|` | `case $day in "понедельник" | "вторник" | "среда") echo "Рабочий день";; "суббота" | "воскресенье") echo "Выходной день";; esac` |
| **Блок `*)`** для обработки всех остальных случаев | Обязателен для обработки некорректных или неожиданных значений |
| **Обработка параметров командной строки** | `case $1 in start) echo "Запуск";; stop) echo "Остановка";; restart) echo "Перезапуск";; *) echo "Использование: $0 {start\|stop\|restart}";; esac` |
| **Вложенность** конструкций `case` | Может быть вложена внутрь других конструкций (case, if, for и т.д.) |

> Конструкция case в Bash — это удобный инструмент для обработки нескольких вариантов одного значения, особенно если нужно проверять одно и то же выражение или переменную на соответствие разным условиям. Она позволяет сделать код более структурированным и легко управляемым, чем при использовании множества операторов if-elif-else.

**Основные преимущества case:**
- Удобное многовариантное ветвление
- Поддержка шаблонов и символов подстановки
- Возможность объединения нескольких условий в одну ветку
- Четкий синтаксис, особенно для большого числа проверок

## Операторы break и continue

> `break` и `continue` — это управляющие операторы в Bash, которые позволяют изменять стандартное поведение циклов. Они помогают контролировать, как и когда цикл завершается или переходит к следующей итерации, пропуская оставшиеся команды в текущем проходе.

- **`break`**: завершает выполнение цикла досрочно. Полезно, когда в процессе выполнения цикла возникает условие, при котором необходимо сразу выйти из цикла.
- **`continue`**: пропускает оставшуюся часть текущей итерации и сразу переходит к следующей итерации цикла. Полезно, когда нужно пропустить определенные условия или значения в цикле.

| `break` | `continue` |
|---------|------------|
| `counter=1; while [ $counter -le 10 ]; do echo "Итерация $counter"; if [ $counter -eq 5 ]; then break; fi; counter=$((counter + 1)); done` | `for i in {1..5}; do if [ $i -eq 3 ]; then continue; fi; echo "Число: $i"; done` |
| Завершает выполнение цикла полностью или его указанный уровень | Пропускает оставшиеся команды в текущей итерации и переходит к следующей |

## Оператор select

> Оператор *select* в Bash используется для создания интерактивного меню, где пользователь может выбрать один из предложенных вариантов. Это особенно полезно для создания простых интерфейсов в скриптах, где нужно дать пользователю возможность выбрать опцию из списка. `select` автоматически создаёт меню и ждёт ввода пользователя, после чего возвращает выбранный элемент.

**Синтаксис:**

```bash
select переменная in список_опций; do
    команды
done
```

**Пример:**

```bash
#!/bin/bash
PS3="Выберите фрукт: "
select fruit in apple banana cherry; do
    case $fruit in
        apple)
            echo "Вы выбрали яблоко"
            ;;
        banana)
            echo "Вы выбрали банан"
            ;;
        cherry)
            echo "Вы выбрали вишню"
            ;;
        *)
            echo "Некорректный выбор"
            ;;
    esac
    break
done
```

**Пояснения:**

1. `PS3` — это встроенная переменная, которая задаёт подсказку для ввода при использовании `select`.
2. Список опций — элементы, из которых пользователь может выбирать.
3. `case` — используется для обработки выбора пользователя.
4. `break` — используется для завершения цикла `select`.

**Особенности select:**
- Нумерация опций: при выводе списка опций `select` автоматически добавляет номера перед каждым пунктом.
- Пользовательский ввод: пользователь должен ввести номер выбранной опции, а не само значение.
- Переменная: выбранная опция присваивается переменной, указанной в начале конструкции `select`. При некорректном вводе переменной присваивается пустое значение.

**Пример создания меню с командами:**

```bash
#!/bin/bash

PS3="Выберите действие: "
select action in "Показать текущую директорию" "Показать содержимое директории" "Выйти"; do
    case $action in
        "Показать текущую директорию")
            pwd
            ;;
        "Показать содержимое директории")
            ls
            ;;
        "Выйти")
            echo "Выход."
            break
            ;;
        *)
            echo "Неверный выбор."
            ;;
    esac
done
```

**Ограничения оператора select:**
- Предназначен для интерактивных скриптов, не подходит для автоматизации выбора без участия пользователя.
- В больших меню может быть неудобен из-за необходимости ручного выбора с клавиатуры.
- Работает только в интерактивных терминалах, не подходит для фоновых процессов.

## Оператор eval

> Оператор `eval` в Bash используется для выполнения строки, содержащей команды. Он позволяет интерпретировать и выполнить динамически созданные команды, что делает его полезным для выполнения сложных команд, составленных программно.

**Синтаксис:**

```bash
eval команда
```

`eval` сначала разворачивает аргументы, а затем повторно интерпретирует их как команду. Это особенно полезно в случаях, когда команда содержится в строке и требуется выполнить её после каких-либо преобразований.

**Пример:**

```bash
#!/bin/bash
command="ls -l"
eval $command
```

Если бы было написано просто `$cmd`, это привело бы к ошибке, так как Bash пытается выполнить строку `ls -l` как имя команды, но не интерпретирует её как отдельные части команды. `eval` помогает развернуть строку в действительную команду.

> **Предупреждение:** `eval` мощен, но его использование может быть **небезопасным**, особенно если строки для выполнения поступают от ненадёжных источников (например, пользовательского ввода). Если строка содержит вредоносный код, он будет выполнен.

**Пример небезопасного использования:**

```bash
#!/bin/bash
read -p "Введите команду: " user_input
eval $user_input
```

Если пользователь введет опасную команду, например `rm -rf /`, она будет выполнена.

### Как избежать опасностей

1. **Проверка вводимых данных**: всегда проверяйте и фильтруйте входные данные, прежде чем использовать их с `eval`.
2. **Минимизируйте использование**: используйте `eval` только в случаях, когда это действительно необходимо.
3. **Избегайте использования пользовательского ввода без обработки**: никогда не используйте `eval` напрямую с несанкционированным вводом пользователя.

**Пример безопасного использования:**

```bash
#!/bin/bash
read -p "Введите команду для выполнения (например, ls -l): " user_input

# Проверим, что пользователь пытается выполнить только безопасную команду
if [[ $user_input == ls* ]]; then
    eval $user_input
else
    echo "Недопустимая команда"
fi
```

## Оператор exit

> Оператор `exit` в Bash используется для завершения выполнения скрипта или выхода из текущей сессии оболочки с определённым кодом завершения (статусом). Это один из базовых инструментов для управления завершением работы скрипта, особенно когда нужно явно указать успешное или ошибочное завершение программы.

**Синтаксис:**

```bash
exit [код_завершения]
```

> `код_завершения` — необязательное число, которое указывает статус завершения. По умолчанию это 0, что означает успешное завершение. Любое ненулевое значение указывает на ошибку или нестандартное завершение программы.

**Пример:**

```bash
#!/bin/bash
if [ "$USER" != "root" ]; then
    echo "Скрипт должен быть выполнен от имени root"
    exit 1
fi

echo "Вы root, скрипт продолжит выполнение"
```

Оператор `exit` полезен для явного завершения скрипта, особенно когда нужно:
- остановить выполнение при возникновении ошибки
- вернуть код завершения, который может быть проанализирован в других скриптах или системах автоматизации

## Дополнительные управляющие конструкции

### Операторы && и || (логические операторы)

Эти операторы позволяют выполнять команды на основе статуса завершения предыдущей команды.

- **`&&` (логическое И)**: следующая команда выполняется, только если предыдущая завершилась **успешно** (статус 0).
- **`||` (логическое ИЛИ)**: следующая команда выполняется, только если предыдущая завершилась **с ошибкой** (статус не равен 0).

**Пример:**

```bash
mkdir new_directory && echo "Каталог создан успешно." || echo "Ошибка при создании каталога."
```

### Оператор trap

`trap` используется для перехвата сигналов и выполнения заданных команд при их получении. Это полезно для очистки ресурсов или корректного завершения скрипта.

**Синтаксис:**

```bash
trap 'команды' сигналы
```

**Пример:**

```bash
#!/bin/bash

cleanup() {
    echo "Очистка ресурсов..."
    # Команды очистки
    exit
}

trap cleanup SIGINT SIGTERM

echo "Скрипт запущен. Нажмите Ctrl+C для выхода."
while true; do
    sleep 1
done
```

При нажатии Ctrl+C (сигнал SIGINT) будет вызвана функция `cleanup`.

### Скобочные операторы

| Описание | Пример |
|----------|--------|
| **Подстановка команд** `$()` и обратные кавычки — позволяют выполнять команду и использовать её вывод | `current_date=$(date); echo "Сегодняшняя дата: $current_date"` |
| **Арифметические выражения** `$(( ))` — для выполнения арифметических операций | `a=5; b=3; sum=$((a + b)); echo "Сумма: $sum"` |
| **Группировка команд `{ }`** — группирует команды в текущем процессе | `{ echo "Первая команда"; echo "Вторая команда"; } > output.txt` |
| **Группировка команд `( )`** — группирует команды в подпроцессе (создаёт новый процесс) | `(a=5; echo "Внутри подпроцесса: a=$a"); echo "Вне подпроцесса: a=${a:-undefined}"` |
| **Условные выражения `[[ ]]`** — расширенные условные выражения, позволяющие использовать регулярные выражения и сложные условия | `if [[ $string == *pattern* ]]; then echo "Строка содержит 'pattern'"; fi` |
