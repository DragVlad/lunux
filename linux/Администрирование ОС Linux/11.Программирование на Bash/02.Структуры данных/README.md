# Структуры данных

> Структуры данных в языках программирования — это способы организации и хранения данных таким образом, чтобы эффективно управлять ими и выполнять операции (вставка, удаление, поиск и т.д.). Они необходимы для решения различных задач, таких как обработка больших объёмов информации, оптимизация доступа к данным или поддержка логики работы программы.

## Зачем нужны структуры данных

1. **Эффективность**: позволяют оптимизировать память и время выполнения операций с данными (поиск, вставка, удаление).
2. **Упрощение управления данными**: удобная организация данных делает их использование более интуитивным.
3. **Поддержка сложных операций**: некоторые структуры данных предоставляют возможность выполнения сложных операций с минимальными затратами времени и ресурсов.
4. **Обработка больших объёмов данных**: поддерживают масштабируемость приложений, работающих с большими объёмами информации.

## Типовые структуры данных

1. **Массивы (Arrays)** — набор элементов одинакового типа, размещённых в непрерывной области памяти.
   - Особенности: быстрый доступ по индексу (O(1)), сложность при добавлении/удалении элементов.
   - Примеры использования: хранение наборов данных фиксированного размера (статических списков, матриц).

2. **Связные списки (Linked Lists)** — элементы данных (узлы) связаны ссылками друг на друга.
   - Типы: односвязные, двусвязные, кольцевые.
   - Особенности: лёгкое добавление/удаление элементов (O(1)), медленный доступ по индексу (O(n)).
   - Примеры использования: реализация стеков, очередей.

3. **Стек (Stack)** — структура с принципом «последним пришёл — первым вышел» (LIFO).
   - Особенности: операции добавления и удаления происходят только на одном конце (вершина стека).
   - Примеры использования: обратная польская нотация, рекурсия, контроль последовательности выполнения задач.

4. **Очередь (Queue)** — структура с принципом «первым пришёл — первым вышел» (FIFO).
   - Типы: обычная очередь, двусторонняя очередь (Deque), приоритетная очередь.
   - Примеры использования: планировщики задач, буферизация данных, обработка запросов в порядке их поступления.

5. **Деревья (Trees)** — иерархическая структура, состоящая из узлов, где один узел является корнем, а остальные — его потомками.
   - Типы: дерево поиска (Binary Search Tree), AVL-деревья, красно-чёрные деревья, B-деревья.
   - Примеры использования: поисковые системы, компиляторы, базы данных.

6. **Хеш-таблицы (Hash Tables)** — структура для быстрого поиска элементов, использующая хеш-функции для вычисления индексов в массиве.
   - Особенности: быстрый поиск (O(1) в среднем случае), возможны коллизии (требуют дополнительных решений: цепочки, открытая адресация).
   - Примеры использования: карты, словари, кэширование.

7. **Графы (Graphs)** — множество вершин и рёбер, где вершины связаны рёбрами.
   - Типы: ориентированные/неориентированные, взвешенные/невзвешенные.
   - Примеры использования: социальные сети, навигационные системы, задачи маршрутизации.

8. **Множества (Sets)** — набор уникальных элементов.
   - Особенности: эффективное хранение и проверка уникальности данных.
   - Примеры использования: удаление дубликатов, проверка наличия элемента.

В Bash поддерживается несколько основных структур данных: переменные, массивы и ассоциативные массивы (словари). Также можно эмулировать списки и другие структуры.

## Переменные

Переменные в Bash — это именованные области памяти, в которых могут храниться данные. Переменные могут быть строковыми, числовыми, а также содержать результаты выполнения команд.

| Описание | Пример |
|----------|--------|
| Объявление и использование переменных | `name="John"`<br>`age=30` |
| Доступ к переменным | `echo "Name: $name, Age: $age"` |
| Чтение значений переменных от пользователя | `read -p "Enter your name: " user_name`<br>`echo "Hello, $user_name!"` |

### Примеры работы с переменными

| Описание | Пример |
|----------|--------|
| Сложение чисел | `a=5`<br>`b=10`<br>`sum=$((a + b))`<br>`echo "Sum: $sum"` |
| Объединение строк (с использованием переменной окружения) | `greeting="Hello"`<br>`message="$greeting, $USER!"`<br>`echo "$message"` |

## Массивы

Bash поддерживает одномерные массивы, которые позволяют хранить несколько значений в одной переменной.

| Описание | Пример |
|----------|--------|
| Объявление массива | `fruits=("apple" "banana" "cherry")` |
| Доступ к элементам массива | `echo "First fruit: ${fruits[0]}"`<br>`echo "Second fruit: ${fruits[1]}"`<br>`echo "Third fruit: ${fruits[2]}"` |
| Перебор всех элементов массива | `for fruit in "${fruits[@]}"; do`<br>&nbsp;&nbsp;`echo "Fruit: $fruit"`<br>`done` |
| Добавление элементов в массив | `fruits+=("orange")` |
| Получение длины массива | `echo "Number of fruits: ${#fruits[@]}"` |
| Удаление элемента массива | `unset fruits[1]`<br>`echo "Fruits after deletion: ${fruits[@]}"` |

## Ассоциативные массивы (словари)

Ассоциативные массивы позволяют хранить пары ключ-значение, что делает их похожими на словари в других языках программирования.

| Описание | Пример |
|----------|--------|
| Объявление ассоциативного массива | `declare -A user`<br>`user[name]="John"`<br>`user[age]=30`<br>`user[email]="john@example.com"` |
| Доступ к элементам ассоциативного массива | `echo "Name: ${user[name]}"`<br>`echo "Age: ${user[age]}"` |
| Перебор всех пар ключ-значение | `for key in "${!user[@]}"; do`<br>&nbsp;&nbsp;`echo "$key: ${user[$key]}"`<br>`done` |
| Удаление элемента ассоциативного массива | `unset user[age]` |

## Списки

В Bash нет прямой поддержки списков, но их можно эмулировать, используя массивы и строки.

| Описание | Пример |
|----------|--------|
| Создание списка с помощью массива | `list=("item1" "item2" "item3")` |
| Добавление элементов в список | `list+=("item4")` |
| Перебор списка | `for item in "${list[@]}"; do`<br>&nbsp;&nbsp;`echo "Item: $item"`<br>`done` |
| Эмуляция списка через строку | `list="item1 item2 item3"`<br>`for item in $list; do`<br>&nbsp;&nbsp;`echo "Item: $item"`<br>`done` |

## Прочие структуры данных

Другие структуры, такие как стек, очередь, множества, деревья, графы или связные списки, также можно реализовать на Bash. Они не являются встроенными и могут быть созданы на базе других структур с использованием пользовательских функций.

Стоит учитывать, что Bash не предназначен для сложных структур данных, и реализация будет не такой производительной и удобной, как в языках вроде Python, C++ или Java. В Bash приходится использовать массивы и ассоциативные массивы (начиная с Bash 4.x).

### Стек (LIFO)

В стек можно добавлять элементы в конец массива и извлекать их оттуда.

```bash
# Инициализация стека
stack=()

# Добавление элемента (push)
push() {
    stack+=("$1")
}

# Удаление элемента (pop)
pop() {
    if [ ${#stack[@]} -eq 0 ]; then
        echo "Стек пуст"
    else
        echo "Извлечен элемент: ${stack[-1]}"
        unset stack[-1]
    fi
}

# Пример использования
push "A"
push "B"
pop    # Выведет B
pop    # Выведет A
```

### Очередь (FIFO)

Для очереди можно использовать массив и удалять элементы с начала.

```bash
# Инициализация очереди
queue=()

# Добавление элемента (enqueue)
enqueue() {
    queue+=("$1")
}

# Удаление элемента (dequeue)
dequeue() {
    if [ ${#queue[@]} -eq 0 ]; then
        echo "Очередь пуста"
    else
        echo "Извлечен элемент: ${queue[0]}"
        queue=("${queue[@]:1}")  # Удаление первого элемента
    fi
}

# Пример использования
enqueue "A"
enqueue "B"
dequeue  # Выведет A
dequeue  # Выведет B
```

### Множества (Set)

В Bash можно использовать ассоциативные массивы для реализации множества, так как в таких массивах ключи уникальны.

```bash
# Инициализация множества
declare -A set

# Добавление элемента в множество
add_to_set() {
    set["$1"]=1
}

# Проверка, есть ли элемент в множестве
contains_in_set() {
    if [[ ${set["$1"]+_} ]]; then
        echo "Элемент $1 присутствует в множестве"
    else
        echo "Элемента $1 нет в множестве"
    fi
}

# Пример использования
add_to_set "A"
add_to_set "B"
contains_in_set "A"  # Выведет, что A присутствует
contains_in_set "C"  # Выведет, что C нет
```

### Связный список

Связные списки можно реализовать с помощью массивов и ассоциативных массивов, где каждый элемент массива содержит ссылку на следующий.

```bash
declare -A linked_list
head=""
tail=""

add_to_list() {
    local value="$1"
    local node=$(uuidgen)  # Генерация уникального идентификатора узла
    
    linked_list[$node,"value"]=$value
    
    if [ -z "$head" ]; then
        head=$node
        tail=$node
    else
        linked_list[$tail,"next"]=$node
        tail=$node
    fi
}

print_list() {
    local node=$head
    while [ -n "$node" ]; do
        echo "${linked_list[$node,value]}"
        node=${linked_list[$node,"next"]}
    done
}

# Пример использования
add_to_list "Node1"
add_to_list "Node2"
print_list
```

### Дерево (Tree)

Дерево можно реализовать с помощью ассоциативных массивов, где каждый узел содержит ссылки на дочерние узлы.

```bash
declare -A tree

add_to_tree() {
    local parent="$1"
    local left_child="$2"
    local right_child="$3"
    
    tree["$parent,left"]=$left_child
    tree["$parent,right"]=$right_child
}

print_tree() {
    local node="$1"
    if [ -z "$node" ]; then
        return
    fi
    echo "Узел: $node"
    print_tree "${tree[$node,left]}"
    print_tree "${tree[$node,right]}"
}

# Пример использования
add_to_tree "root" "left_child" "right_child"
add_to_tree "left_child" "left_left_child" "left_right_child"
print_tree "root"
```

## Методы работы со структурами данных

Bash предоставляет множество встроенных команд для работы с переменными и массивами:

- `declare` — используется для объявления переменных и массивов
- `unset` — удаляет переменные или элементы массивов
- `read` — считывает данные с клавиатуры или из файла
- `echo` — выводит значение переменной или строки на экран

### Пример работы с переменными и массивами

```bash
#!/bin/bash
declare -A user
user[name]="Alice"
user[age]=25
user[city]="New York"

echo "User details:"
for key in "${!user[@]}"; do
  echo "$key: ${user[$key]}"
done

# Обновление значения
user[city]="Los Angeles"
echo "Updated city: ${user[city]}"
```
