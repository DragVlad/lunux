# Переменные окружения в Linux

**Переменные окружения** — это динамические значения, которые влияют на поведение процессов в операционной системе. Они представляют собой пары «ключ-значение» и используются для хранения информации, такой как пути к исполняемым файлам, настройки окружения и данные конфигурации.

> Переменные окружения играют важную роль в работе Linux. Они содержат информацию, которая используется программами и сценариями для выполнения различных задач.

---

## Важнейшие переменные окружения

| Переменная | Значение | Как посмотреть |
|------------|----------|----------------|
| `PATH` | Список каталогов, где система ищет исполняемые файлы | `echo $PATH` |
| `HOME` | Домашний каталог текущего пользователя | `echo $HOME` |
| `USER` | Имя текущего пользователя | `echo $USER` |
| `SHELL` | Текущая командная оболочка | `echo $SHELL` |
| `LANG` | Язык и региональные настройки | `echo $LANG` |
| `PWD` | Текущий рабочий каталог | `echo $PWD` |
| `EDITOR` | Предпочтительный текстовый редактор (по умолчанию) | `echo $EDITOR` |

---

## Управление переменными

### Просмотр всех переменных

Чтобы увидеть **все** переменные окружения:

```bash
printenv
env
```

### Просмотр конкретной переменной

Используйте `echo` с синтаксисом `$VARIABLE_NAME`:

```bash
echo $HOME
echo $PATH
```

### Создание новой переменной

```bash
export MY_VARIABLE="Hello, World!"
echo $MY_VARIABLE
```

### Изменение существующей переменной

```bash
export PATH=$PATH:/new/path
echo $PATH
```

> [!note]
> Переменные, созданные или изменённые таким образом, доступны **только в текущей сессии** оболочки и исчезают после её завершения.

### Удаление переменной

```bash
unset MY_VARIABLE
echo $MY_VARIABLE   # ничего не выведет
```

## Файлы конфигурации оболочки

Для **постоянного** задания переменных их нужно добавить в файлы конфигурации. Эти файлы загружаются при запуске оболочки.

### Для bash

| Файл | Назначение |
|------|------------|
| `~/.bashrc` | Загружается для каждой интерактивной сессии |
| `~/.bash_profile` | Загружается при входе в систему |

### Для zsh

| Файл | Назначение |
|------|------------|
| `~/.zshrc` | Загружается для каждой интерактивной сессии |
| `~/.zprofile` | Загружается при входе в систему |

### Пример добавления переменной в `~/.bashrc`

```bash
echo 'export MY_VARIABLE="Hello, World!"' >> ~/.bashrc
source ~/.bashrc
```

> [!tip]
> Команда `source` применяет изменения без перезапуска терминала.

## Примеры использования

### Настройка PATH

Добавление нового пути позволяет системе находить исполняемые файлы в указанном каталоге:

```bash
export PATH=$PATH:/home/user/bin
```

### Настройка EDITOR

Установка текстового редактора по умолчанию:

```bash
export EDITOR=nano
```

### Настройка JAVA_HOME

Путь к установленной Java (часто требуется для разработки):

```bash
export JAVA_HOME=/usr/lib/jvm/java-11-openjdk-amd64
export PATH=$JAVA_HOME/bin:$PATH
```
