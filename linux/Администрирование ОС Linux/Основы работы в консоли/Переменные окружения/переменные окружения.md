# Переменные окружения

Переменные окружения — это динамические значения, которые могут влиять на поведение процессов в операционной системе. Они представляют собой пары «ключ-значение» и используются для хранения информации, такой, как пути к исполняемым файлам, настройки окружения и данные конфигурации.

```bash
env # показывает все переменные окружения
export MY_VARIBLE="Hello, World!" # задаем переменную
echo $MY_VARIBLE
unset MY_VARIBLE # удаление переменной
```
