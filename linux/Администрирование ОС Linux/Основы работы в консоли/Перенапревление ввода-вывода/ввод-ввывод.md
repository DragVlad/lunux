# Перенаправление ввода ввывода

Есть 3 потока:
- stdin = 0 - ввод данных в программах
- stdout = 1 - вывод данных из программы
- stderr = 2 - вывод ошибок программы

```bash
# базовое перенаправление потока
ls -lah > output.txt # перезапись файла
ls -lah >> output.txt # дозапись в конец файла
ls error_dir > output.txt 2>&1 # перенаправляем поток stderr, в поток stdout

wc -l < output.txt # направляем на вход wc содержимое output.txt
ls -lah | wc -l # создание конвеера, направляем вывод первой команды как аргументы во вторую
ls -la | grep *.txt 
```
