# Перенаправление ввода/вывода и пайпы в Linux

Мы прошли два важных стартовых блока. Пришло время заняться маленькими, но сугубо практическими задачами, **цель которых** — освоить базовые навыки работы с командной оболочкой Linux. И первая из этих тем: связывание команд между собой за счёт перенаправления ввода/вывода.

> Перенаправление ввода/вывода и использование пайпов — это основные техники командной строки, которые позволяют перенаправлять потоки данных между командами и файлами. Эти возможности делают командную строку Linux чрезвычайно мощным инструментом для обработки данных и автоматизации задач.

Вы можете сохранять что-то для дальнейшей обработки или собирать целые массивы команд в удобные и эффективные скрипты-однострочники.

---

## Три стандартных потока

В Linux и других Unix-подобных системах каждая запущенная программа имеет **три стандартных потока**:

1. **Стандартный ввод (stdin)**
   - Используется для ввода данных в программу. По умолчанию — клавиатура.
   - Обозначается как **0**

2. **Стандартный вывод (stdout)**
   - Используется для вывода данных программы. По умолчанию — экран (терминал).
   - Обозначается как **1**

3. **Стандартный поток ошибок (stderr)**
   - Используется для вывода сообщений об ошибках. По умолчанию — экран (терминал).
   - Обозначается как **2**

> [!note]
> Ранее, когда мы смотрели файловые дескрипторы команды `ping`, видели: 0 был связан с терминалом, а остальные 2 были направлены в `/dev/null`. Вы можете (и вам периодически придётся) взаимодействовать с этими потоками, перенаправляя результаты работы одной программы на вход другой.

## Перенаправление вывода

Перенаправление вывода отправляет вывод команды в файл или другое место вместо стандартного вывода (экрана).

### Запись в файл (с перезаписью)

```bash
команда > файл
```

**Пример:**
```bash
ls > output.txt
```
Записывает вывод `ls` в файл `output.txt`.

### Добавление в конец файла

```bash
команда >> файл
```

**Пример:**
```bash
echo "Hello, World!" >> output.txt
```
Добавляет строку в конец файла.

### Перенаправление stdout и stderr в один файл

```bash
команда > файл 2>&1
```

**Пример:**
```bash
ls /nonexistent > output.txt 2>&1
```
Записывает и вывод, и ошибки в `output.txt`.

### Перенаправление только ошибок

```bash
команда 2> файл
```

**Пример:**
```bash
ls /nonexistent 2> error.txt
```
Записывает только ошибки в `error.txt`.

## Перенаправление ввода

Перенаправление ввода подаёт содержимое файла в качестве входных данных команды вместо клавиатуры.

```bash
команда < файл
```

**Пример:**
```bash
wc -l < input.txt
```
Считает количество строк в файле `input.txt`.

## Пайпы (каналы)

> Пайпы используются для передачи вывода одной команды в качестве ввода другой. Это позволяет создавать цепочки команд для обработки данных — их иногда называют конвейерами.

### Базовый пайп

```bash
команда1 | команда2
```

**Пример:**
```bash
ls -l | grep ".txt"
```
Передаёт вывод `ls -l` в `grep`, который фильтрует строки с `.txt`.

### Цепочки команд

```bash
команда1 | команда2 | команда3
```

**Пример (анализ частоты слов):**
```bash
cat file.txt | tr ' ' '\n' | sort | uniq -c | sort -nr
```

> [!tip]
> Это типичный **скрипт-однострочник**. Комбинация утилит в одну строчку решает трудоёмкую задачу: разбивает содержимое `file.txt` на слова, сортирует, подсчитывает уникальные слова и сортирует по частоте.

## Примеры использования

### Сохранение вывода команды в файл

Записываем информацию о свободном месте на диске:

```bash
df -h > disk_usage.txt
```

### Запись ошибок в файл для анализа

Ищем файлы `*.log`, ошибки сохраняем отдельно:

```bash
find / -name "*.log" 2> errors.txt
```

### Фильтрация процессов

Показываем только процессы с `apache` в имени:

```bash
ps aux | grep apache
```

### Одновременный вывод на экран и в файл

Перенаправляем ошибки и вывод в файл, а также отображаем их на экране с помощью `tee`:

```bash
(ls -l /invalid_directory 2>&1) | tee output.txt
```
