# Права доступа в Linux

## Пользователи и группы (кратко)

Для изучения прав доступа необходимо понимать концепцию пользователей и групп. Рассмотрим ключевые моменты.

| Понятие | Описание |
|---------|----------|
| **Пользователь** | Учётная запись с уникальным идентификатором (UID) и набором прав |
| **Группа** | Объединение пользователей с уникальным идентификатором (GID) для упрощения управления правами |

**Зачем нужны пользователи и группы:**
- **Безопасность** — ограничение доступа к файлам, процессам и ресурсам
- **Управление правами** — упрощение доступа для нескольких пользователей одновременно
- **Аудит** — отслеживание действий каждого пользователя

---

## Схема прав (r, w, x)

### Три типа прав

| Право | Для файла | Для каталога |
|-------|-----------|--------------|
| **r** (read) | Просмотр содержимого файла | Просмотр списка файлов в каталоге |
| **w** (write) | Изменение содержимого файла | Создание, удаление, переименование файлов |
| **x** (execute) | Выполнение файла как программы | Доступ к содержимому каталога (cd) |

### Три категории пользователей

| Категория | Описание |
|-----------|----------|
| **Владелец** (owner) | Пользователь, создавший файл |
| **Группа** (group) | Группа владельца |
| **Остальные** (others) | Все остальные пользователи системы |

---

## Формат отображения прав

Права отображаются в виде строки из **10 символов**:

```
-rwxr-xr--
││││││││││
│││││││││└─ права для остальных (read)
││││││││└── права для остальных (write)
│││││││└─── права для остальных (execute)
││││││└──── права для группы (read)
│││││└───── права для группы (write)
││││└────── права для группы (execute)
│││└─────── права для владельца (read)
││└──────── права для владельца (write)
│└───────── права для владельца (execute)
└────────── тип файла (- = обычный файл, d = каталог)
```

### Примеры

| Строка прав | Расшифровка |
|-------------|-------------|
| `-rwxr-xr--` | Владелец: rwx (чтение, запись, выполнение)<br>Группа: r-x (чтение, выполнение)<br>Остальные: r-- (только чтение) |
| `drwxr-xr-x` | Каталог, права: 755 |
| `-rw-r--r--` | Обычный файл, права: 644 |

## Команды для управления правами

### chmod (change mode) — изменение прав доступа

**Символьный способ:**

| Оператор | Значение |
|----------|----------|
| `u` | user (владелец) |
| `g` | group (группа) |
| `o` | others (остальные) |
| `a` | all (все) |
| `+` | добавить право |
| `-` | убрать право |
| `=` | установить точно |

```bash
chmod u+x file.txt      # добавить выполнение для владельца
chmod g-w file.txt      # убрать запись для группы
chmod o=r file.txt      # для остальных только чтение
chmod a+x script.sh     # добавить выполнение для всех
```

**Цифровой (восьмеричный) способ:**

| Цифра | Права | Двоичный код |
|-------|-------|--------------|
| 0 | `---` | 000 |
| 1 | `--x` | 001 |
| 2 | `-w-` | 010 |
| 3 | `-wx` | 011 |
| 4 | `r--` | 100 |
| 5 | `r-x` | 101 |
| 6 | `rw-` | 110 |
| 7 | `rwx` | 111 |

```bash
chmod 755 file.txt   # владелец: 7 (rwx), группа: 5 (r-x), остальные: 5 (r-x)
chmod 644 file.txt   # владелец: 6 (rw-), группа: 4 (r--), остальные: 4 (r--)
```

### chown (change owner) — изменение владельца

```bash
chown user1 file.txt            # изменить владельца
chown user1:group1 file.txt     # изменить владельца и группу
chown :group1 file.txt          # изменить только группу
chown -R user1:group1 /path/    # рекурсивно для каталога
```

### chgrp (change group) — изменение группы

```bash
chgrp group1 file.txt           # изменить группу
chgrp -R group1 /path/          # рекурсивно для каталога
```

## Специальные права (SUID, SGID, Sticky bit)

| Спецправо | Буква | Для файлов | Для каталогов |
|-----------|-------|------------|---------------|
| **SUID** | `s` (на месте x владельца) | Выполняется с правами владельца файла | (не применяется) |
| **SGID** | `s` (на месте x группы) | Выполняется с правами группы файла | Новые файлы наследуют группу каталога |
| **Sticky bit** | `t` (на месте x остальных) | (не применяется) | Только владелец может удалять свои файлы |

### Примеры использования

| Команда | Результат |
|---------|-----------|
| `chmod u+s /path/to/file` | Установить SUID |
| `chmod g+s /path/to/dir` | Установить SGID на каталог |
| `chmod +t /path/to/dir` | Установить Sticky bit |

### Визуальное отображение

| Без спецправ | Со спецправами |
|-------------|----------------|
| `-rwxr-xr-x` | `-rwsr-xr-x` (SUID) |
| `-rwxr-xr-x` | `-rwxr-sr-x` (SGID) |
| `drwxrwxrwx` | `drwxrwxrwt` (Sticky bit) |

> [!note]
> Sticky bit чаще всего используется в каталоге `/tmp`: `drwxrwxrwt`. Это позволяет пользователям создавать файлы, но удалять только свои.

## Таблица быстрого доступа

| Задача | Команда |
|--------|---------|
| Просмотр прав | `ls -l` или `stat file` |
| Установка прав (символы) | `chmod u+rwx,g+rx,o+r file` |
| Установка прав (цифры) | `chmod 755 file` |
| Смена владельца | `chown user:group file` |
| Смена группы | `chgrp group file` |
| Установка SUID | `chmod u+s file` |
| Установка SGID | `chmod g+s file` |
| Установка Sticky bit | `chmod +t dir` |
