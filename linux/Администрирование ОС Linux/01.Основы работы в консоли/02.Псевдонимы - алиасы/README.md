# Псевдонимы (алиасы) команд в Linux

**Алиас (alias)** — это короткое имя, которое заменяет длинную команду или цепочку команд с параметрами. Алиасы экономят время и уменьшают количество опечаток.

## Создание и удаление алиасов

### Временный алиас (действует до закрытия терминала)

```bash
alias ll='ls -l'
alias gs='git status'
alias update='sudo apt update && sudo apt upgrade -y'
```

### Просмотр всех активных алиасов

```bash
alias
```

### Удаление алиаса

```bash
unalias ll
```

### Удаление всех алиасов

```bash
unalias -a
```

## Постоянные алиасы

Чтобы алиасы сохранялись после перезагрузки, их нужно добавить в файл конфигурации оболочки.

| Оболочка | Файл |
|----------|------|
| `bash` | `~/.bashrc` или `~/.bash_aliases` |
| `zsh` | `~/.zshrc` |

### Пример добавления

```bash
echo "alias ll='ls -lh'" >> ~/.bashrc
echo "alias la='ls -la'" >> ~/.bashrc
source ~/.bashrc
```

> Если вы создадите отдельный файл `~/.bash_aliases`, он автоматически подхватится `~/.bashrc` (в Ubuntu это настроено по умолчанию).

## Специальные возможности

### Алиас с аргументами

Алиас может принимать аргументы — они просто добавляются в конец:

```bash
alias mkcd='mkdir -p $1 && cd $1'
# Использование:
mkcd mydir/newdir
```

### Алиас для перехода в часто используемые папки

```bash
alias projects='cd ~/Documents/projects'
alias logs='cd /var/log && ls -lt | head'
```

### Обход существующих команд

Если назвать алиас так же, как существующую команду, он её переопределит:

```bash
alias ls='ls --color=auto'
```

### Использование `sudo` с алиасом

```bash
alias rm='rm -i'           # запрашивать подтверждение
alias rmrf='rm -rf'        # для опасных операций
```

## Полезные алиасы для повседневной работы

| Алиас | Команда | Что делает |
|-------|---------|-------------|
| `ll` | `ls -lh` | Подробный список файлов, размеры в человекочитаемом виде |
| `la` | `ls -la` | Все файлы (включая скрытые) с правами |
| `lt` | `ls -lt` | Сортировка по времени изменения |
| `..` | `cd ..` | На уровень вверх |
| `...` | `cd ../..` | На два уровня вверх |
| `h` | `history` | Показать историю команд |
| `paths` | `echo $PATH \| tr ':' '\n'` | Показать все пути в `PATH` |
| `ports` | `ss -tulnp` | Список открытых портов с процессами |
| `myip` | `curl ifconfig.me` | Внешний IP-адрес |
| `dfh` | `df -h` | Свободное место на дисках |
| `duh` | `du -sh *` | Размер файлов и папок в текущей директории |

## Опасные моменты

> [!warning]
> Если алиас переопределяет системную команду, будьте осторожны.
> ```bash
> alias rm='rm -rf'   # крайне не рекомендуется!
> ```
> Вместо этого лучше создать отдельное имя:
> ```bash
> alias nuke='rm -rf'
> ```

## Отключение алиаса временно

Если вы хотите выполнить оригинальную команду, обойдя алиас:

```bash
\ls          # обратный слэш перед командой
"ls"         # кавычки
command ls   # ключевое слово command
```

## Где хранятся системные алиасы?

В Ubuntu и многих дистрибутивах уже есть встроенные алиасы. Они находятся в:

```bash
/etc/bash.bashrc      # системные (для всех пользователей)
~/.bashrc             # пользовательские
```

Пример системных алиасов (Ubuntu):
```bash
alias ll='ls -alF'
alias la='ls -A'
alias l='ls -CF'
```

## Итог

- Алиасы работают **только в интерактивной оболочке**, не в скриптах
- Для постоянного использования добавляйте в `~/.bashrc` или `~/.bash_aliases`
- Не переопределяйте опасные команды без веской причины
- После добавления примените `source ~/.bashrc`
