# Перенаправление ввода-вывода и пайпы в Linux

## Три стандартных потока

Каждая программа в Linux имеет три стандартных потока:

| Поток | Дескриптор | Символ | Назначение | Источник/Приёмник |
|-------|-----------|--------|------------|-------------------|
| Стандартный ввод | 0 | `stdin` | Ввод данных | клавиатура |
| Стандартный вывод | 1 | `stdout` | Вывод результата | экран |
| Стандартный вывод ошибок | 2 | `stderr` | Вывод ошибок | экран |

> [!note]
> Разделение `stdout` и `stderr` позволяет обрабатывать ошибки отдельно от обычного вывода программы.

## Перенаправление вывода (`>` и `>>`)

### Перенаправление stdout в файл (с перезаписью)

```bash
команда > файл
```

**Пример:**
```bash
ls > files.txt          # список файлов запишется в files.txt
echo "Hello" > test.txt # файл test.txt будет содержать "Hello"
```

### Перенаправление stdout в файл (с добавлением)

```bash
команда >> файл
```

**Пример:**
```bash
echo "World" >> test.txt    # добавит "World" в конец test.txt
ls >> files.txt             # добавит список файлов в конец files.txt
```

### Перенаправление stderr (только ошибки)

```bash
команда 2> файл
```

**Пример:**
```bash
ls /несуществующая_папка 2> errors.txt   # ошибка уйдёт в errors.txt
```

### Перенаправление stdout и stderr в один файл

```bash
команда > файл 2>&1
# или
команда &> файл
```

**Пример:**
```bash
ls /existing /nonexisting > all.txt 2>&1
ls /existing /nonexisting &> all.txt    # тот же результат, короче
```

### Перенаправление в никуда (`/dev/null`)

```bash
команда 2>/dev/null     # скрыть ошибки
команда >/dev/null      # скрыть обычный вывод
команда &>/dev/null     # скрыть всё
```

> [!tip]
> `/dev/null` — специальное устройство, которое «съедает» всё, что в него отправляют.

## Перенаправление ввода (`<`)

### Чтение из файла вместо клавиатуры

```bash
команда < файл
```

**Пример:**
```bash
sort < list.txt         # отсортирует строки из list.txt
wc -l < file.txt        # посчитает строки в file.txt
mysql -u root < dump.sql # выполнит SQL-запросы из файла
```

## Пайпы (каналы) — `|`

Пайп передаёт вывод одной команды на ввод другой.

### Базовый пайп

```bash
команда1 | команда2
```

**Пример:**
```bash
ls -l | grep ".txt"     # показать только .txt файлы
ps aux | grep nginx     # найти процесс nginx
```

### Цепочка из нескольких пайпов

```bash
команда1 | команда2 | команда3
```

**Пример:**
```bash
cat file.txt | sort | uniq -c | sort -nr
# разобрать по частям:
# 1. cat — вывести содержимое
# 2. sort — отсортировать строки
# 3. uniq -c — подсчитать повторы
# 4. sort -nr — отсортировать по убыванию частоты
```

### С пайпом и перенаправлением в файл

```bash
ps aux | grep nginx > nginx_processes.txt
```

## Команда `tee` — вывод на экран и в файл одновременно

```bash
команда | tee файл
```

**Пример:**
```bash
ls -l | tee list.txt        # вывести на экран И сохранить в файл
ls -l | tee -a list.txt     # добавить в конец файла (-a = append)
```

## Полезные комбинации

| Задача | Команда |
|--------|---------|
| Подсчитать количество файлов | `ls -1 \| wc -l` |
| Найти строку в логах | `cat /var/log/syslog \| grep "error"` |
| Показать топ-10 процессов по памяти | `ps aux \| sort -rnk 4 \| head -10` |
| Найти самый большой файл | `find . -type f -exec du -h {} + \| sort -rh \| head -5` |
| Пинг с записью в файл и выводом на экран | `ping google.com \| tee ping.log` |

## Таблица быстрого доступа

| Синтаксис | Что делает |
|-----------|------------|
| `cmd > file` | stdout в файл (перезапись) |
| `cmd >> file` | stdout в файл (добавление) |
| `cmd 2> file` | stderr в файл |
| `cmd &> file` | stdout и stderr в файл |
| `cmd > file 2>&1` | stdout и stderr в один файл |
| `cmd < file` | читать из файла как stdin |
| `cmd1 \| cmd2` | передать stdout cmd1 в stdin cmd2 |
| `cmd \| tee file` | вывести на экран и сохранить в файл |
| `cmd > /dev/null` | скрыть stdout |
| `cmd 2>/dev/null` | скрыть stderr |

---

## Итог

1. **`>`** — направить вывод в файл (сотрёт старое содержимое)
2. **`>>`** — добавить вывод в конец файла
3. **`2>`** — направить ошибки в файл
4. **`<`** — взять ввод из файла
5. **`\|`** — передать вывод одной команды другой
6. **`tee`** — вывести на экран и сохранить в файл
7. **`/dev/null`** — чёрная дыра, всё туда отправленное исчезает
