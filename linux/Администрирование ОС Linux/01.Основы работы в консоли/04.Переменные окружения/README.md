# Переменные окружения

## Что такое переменные окружения

**Переменные окружения** (environment variables) — это именованные значения, которые влияют на поведение процессов в операционной системе. Они представляют собой пары `КЛЮЧ=ЗНАЧЕНИЕ` и используются для хранения информации о системном окружении: путях к исполняемым файлам, настройках локали, домашних каталогах и т.д.

> [!note]
> Переменные окружения передаются от родительского процесса дочернему. Если вы измените переменную в терминале, она повлияет только на процессы, запущенные из этого терминала.

---

## Просмотр переменных окружения

| Команда | Что делает |
|---------|------------|
| `printenv` | Показать все переменные окружения |
| `env` | Показать все переменные окружения (аналог) |
| `echo $ПЕРЕМЕННАЯ` | Показать значение конкретной переменной |
| `set` | Показать все переменные (включая локальные переменные оболочки) |

### Примеры

```bash
printenv                     # все переменные
echo $HOME                   # /home/username
echo $PATH                   # список путей поиска программ
echo $SHELL                  # /bin/bash (или /bin/zsh)
```

---

## Важнейшие переменные окружения

| Переменная | Значение | Пример |
|------------|----------|--------|
| `HOME` | Домашний каталог текущего пользователя | `/home/alice` |
| `USER` | Имя текущего пользователя | `alice` |
| `SHELL` | Путь к командной оболочке | `/bin/bash` |
| `PATH` | Список каталогов, где система ищет исполняемые файлы | `/usr/local/bin:/usr/bin:/bin` |
| `PWD` | Текущий рабочий каталог | `/home/alice/projects` |
| `OLDPWD` | Предыдущий рабочий каталог | `/home/alice` |
| `LANG` | Язык и региональные настройки | `en_US.UTF-8` |
| `EDITOR` | Предпочтительный текстовый редактор | `nano` или `vim` |
| `PS1` | Формат приглашения командной строки | `\u@\h:\w\$` |

> [!tip]
> Переменная `PATH` — одна из самых важных. Когда вы вводите `ls`, система последовательно ищет исполняемый файл `ls` во всех каталогах из `PATH` и запускает первый найденный.

## Создание и изменение переменных

### Локальная переменная (только для текущей оболочки)

```bash
MY_VAR="Hello"
echo $MY_VAR          # Hello
```

### Экспорт переменной (доступна дочерним процессам)

```bash
export MY_VAR="Hello"
```

### Добавление каталога в PATH

```bash
export PATH=$PATH:/home/username/my_scripts
```

### Удаление переменной

```bash
unset MY_VAR
```

---

## Типы переменных

| Тип | Область видимости | Как создать | Пример |
|-----|-------------------|-------------|--------|
| **Локальные** | Только текущая оболочка | `VAR=value` | `TEMP=/tmp` |
| **Экспортированные (окружения)** | Текущая оболочка и все дочерние процессы | `export VAR=value` | `export EDITOR=nano` |

### Демонстрация разницы

```bash
# Локальная переменная
LOCAL_VAR="only me"
bash                    # запускаем дочернюю оболочку
echo $LOCAL_VAR         # ничего — переменная не видна
exit                    # выходим из дочерней

# Экспортированная переменная
export EXPORTED_VAR="visible"
bash
echo $EXPORTED_VAR      # visible — переменная видна
exit
```

## Постоянное хранение переменных

Переменные, созданные в терминале, живут только до его закрытия. Чтобы сделать их постоянными, нужно добавить команды в конфигурационные файлы.

### Файлы конфигурации для bash

| Файл | Когда загружается | Для чего |
|------|-------------------|----------|
| `~/.bashrc` | Каждая интерактивная сессия (новый терминал) | Алиасы, функции, переменные для интерактивной работы |
| `~/.bash_profile` | При входе в систему (логин) | Переменные окружения, запуск программ |
| `~/.profile` | Если нет `.bash_profile` | Кросc-оболочковые настройки |
| `/etc/bash.bashrc` | Глобальный для всех пользователей | Системные настройки (требует `sudo`) |

> [!important]
> **Правило:** переменные окружения (`export`) кладите в `~/.bash_profile`. Алиасы и функции — в `~/.bashrc`. Некоторые дистрибутивы (например, Ubuntu) загружают `~/.bashrc` из `~/.profile`, поэтому разница может стираться.

### Пример добавления постоянной переменной

```bash
# Добавить переменную в ~/.bash_profile
echo 'export EDITOR=nano' >> ~/.bash_profile

# Применить изменения без перезахода
source ~/.bash_profile

# Проверить
echo $EDITOR            # nano
```

### Типичные настройки в .bash_profile

```bash
# Пути
export PATH="$HOME/.local/bin:$PATH"

# Редактор по умолчанию
export EDITOR=nano
export VISUAL=nano

# Локаль
export LANG=en_US.UTF-8

# Опции истории
export HISTSIZE=10000
export HISTFILESIZE=20000
```

## Переменные окружения и права доступа

### Переменные для sudo

По соображениям безопасности `sudo` по умолчанию **не передаёт** переменные окружения пользователя.

```bash
export MY_SECRET="data"
sudo echo $MY_SECRET    # ничего не выведет
```

Чтобы передать конкретную переменную:

```bash
sudo --preserve-env=MY_SECRET echo $MY_SECRET
```

Или сохранить все переменные:

```bash
sudo --preserve-env
```

### Настройка безопасных переменных через sudoers

В файле `/etc/sudoers` (через `visudo`) можно разрешить передачу определённых переменных:

```bash
Defaults env_keep += "MY_SECRET EDITOR"
```

## Практические примеры использования

### 1. Настройка JAVA_HOME для разработки

```bash
export JAVA_HOME=/usr/lib/jvm/java-11-openjdk-amd64
export PATH=$JAVA_HOME/bin:$PATH
```

### 2. Смена приглашения командной строки (PS1)

```bash
# Стандартное: пользователь@хост:путь$
export PS1="\u@\h:\w\$ "

# Минимальное: $ 
export PS1="\$ "

# С цветом: [user@host] ~ $
export PS1="\[\033[01;32m\]\u@\h\[\033[00m\]:\[\033[01;34m\]\w\[\033[00m\]\$ "
```

| Код | Значение |
|-----|----------|
| `\u` | имя пользователя |
| `\h` | имя хоста |
| `\w` | полный путь |
| `\W` | только имя текущего каталога |
| `\$` | `$` (обычный) или `#` (root) |

### 3. Временное изменение локали для команды

```bash
LANG=ru_RU.UTF-8 date    # дата по-русски
LANG=C ls                # сортировка в стиле C (ASCII)
```

### 4. Отладка: просмотр PATH

```bash
echo $PATH | tr ':' '\n'   # каждый путь на новой строке
```

## Команда `env` — запуск с изменённым окружением

```bash
# Запустить программу с дополнительной переменной
env MY_VAR=test ./script.sh

# Очистить окружение и запустить с новыми переменными
env -i PATH=/bin HOME=/tmp bash
```

## Шпаргалка

| Задача | Команда |
|--------|---------|
| Показать все переменные | `printenv` |
| Показать значение | `echo $VAR` |
| Создать локальную | `VAR=value` |
| Создать экспортированную | `export VAR=value` |
| Удалить | `unset VAR` |
| Добавить в PATH | `export PATH=$PATH:/new/path` |
| Сделать постоянной | Добавить в `~/.bash_profile` |
| Применить изменения | `source ~/.bash_profile` |

---

## Итог

1. **Переменные окружения** — это пары `КЛЮЧ=ЗНАЧЕНИЕ`, влияющие на поведение процессов
2. **`PATH`** — самая важная переменная, определяет, где система ищет программы
3. **Локальные** переменные видны только текущей оболочке, **экспортированные** — дочерним процессам
4. Для **постоянного** хранения добавляйте `export` в `~/.bash_profile`
5. `sudo` по умолчанию **не передаёт** ваши переменные — используйте `--preserve-env`

> [!tip]
> После изменения `~/.bash_profile` выполните `source ~/.bash_profile` или откройте новый терминал. Перезагрузка не требуется.
