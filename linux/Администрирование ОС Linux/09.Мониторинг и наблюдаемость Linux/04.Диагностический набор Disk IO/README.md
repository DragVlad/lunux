# Disk I/O

Если **CPU — это сердце**, а **RAM — мозг**, то **диск — желудок** системы: именно туда сбрасывается, сохраняется и откуда читается всё, что не умещается в ОЗУ. Если «пищеварение» замедляется — тормозит вся система.

## iostat

`iostat` — первая линия диагностики дисковых операций.

```bash
iostat 1 5
```

Утилита `iostat` из пакета `sysstat` показывает статистику по дисковым устройствам, включая:
- `r/s`, `w/s` — число операций чтения и записи в секунду (**IOPS**)
- `rkB/s`, `wkB/s` — объём переданных данных в килобайтах в секунду

**Расширенный вывод `iostat -x`:**

```bash
iostat -x 1 5
```

В расширенном режиме добавляются группы значений с префиксами `r` (Read), `w` (Write), `d` (Discard — операции удаления блоков, например TRIM на SSD):

| Поле | Значение |
|------|----------|
| `r/s`, `w/s`, `d/s` | Количество операций в секунду (IOPS) |
| `rkB/s`, `wkB/s`, `dkB/s` | Количество переданных данных (в килобайтах/с) |
| `rrqm/s`, `wrqm/s`, `drqm/s` | Количество объединённых операций в очередь (merged I/O requests) |
| `%rrqm`, `%wrqm`, `%drqm` | Процент объединённых запросов к общему числу |
| `r_await`, `w_await`, `d_await` | Среднее время ожидания выполнения запроса (в мс) |
| `rareq-sz`, `wareq-sz`, `dareq-sz` | Средний размер запроса (в кБ) |

**Дополнительные важные поля:**

- `%util` — доля времени, когда устройство было занято.
- `aqu-sz` (Average Queue Size) — среднее количество запросов в очереди к устройству. Значение `aqu-sz > 1` означает, что диск не справляется.

**Рекомендации по интерпретации:**

- `await > 20 мс` на HDD или `await > 5 мс` на SSD — плохой симптом, повод разобраться.
- `%util ≈ 100%` — диск работает на пределе, возможны задержки.

### Пример: нагрузка на диск с помощью Python

```python
import time

FILE_PATH = "loadtest.bin"
CHUNK_SIZE = 1024 * 1024  # 1 MB
RUN_TIME = 10  # секунд

while True:
    # === Запись ===
    with open(FILE_PATH, "wb") as f:
        start = time.time()
        while time.time() - start < RUN_TIME:
            f.seek(0)  # перезаписываем с начала
            f.write(b"0" * CHUNK_SIZE)
            f.flush()
    print("Write phase done")

    # === Чтение ===
    with open(FILE_PATH, "rb") as f:
        start = time.time()
        while time.time() - start < RUN_TIME:
            f.seek(0)
            data = f.read(CHUNK_SIZE)
    print("Read phase done")
```

При выполнении этого скрипта в `iostat`, `iotop`, `vmstat` будут видны рост `await`, `wa`, `%util`.

## iotop

`iotop` — интерактивная утилита, показывающая, **какие именно процессы** генерируют нагрузку на диск: объёмы чтения, записи, процент от общего I/O.

```bash
sudo apt install -y iotop
sudo iotop
```

Полезна при спайках или постоянной нагрузке для быстрого поиска виновника.

## vmstat и диски

```bash
vmstat 1 5
```

В контексте дискового I/O в `vmstat` обращают внимание на:

- `wa` (wait) — доля времени CPU, потраченного на ожидание I/O.
- `b` — количество процессов, заблокированных в ожидании I/O.

### Пример: чтение файла без конца

```python
# Постоянное чтение файла
with open("/var/log/syslog", "rb") as f:
    while True:
        f.read(1024 * 1024)  # Читаем по 1 МБ
```

## df и du

Эти утилиты используются для анализа утилизации пространства на диске.

**df — информация о точках монтирования:**

```bash
df -h
```

Показывает общий объём, использованное и свободное место по точкам монтирования.

Флаг `-i` показывает использование inode:

```bash
df -i
```

Если **inode закончились** — создание новых файлов станет невозможным, даже если есть свободное место.

**du — размер директорий:**

```bash
du -sh * | sort -h
```

Показывает размер директорий в текущем каталоге. Удобно искать «обжор»: папки с логами, дампами и т.п.

## Дополнительные инструменты

| Утилита | Назначение |
|---------|------------|
| `blktrace` | Трассировка низкоуровневой активности диска |
| `ioping` | Измеряет latency I/O операций. Аналог ping, но для диска |

## Современные альтернативы

| Утилита | Особенности |
|---------|-------------|
| [glances](http://glances.readthedocs.io) | Всё в одном: CPU, диск, сеть, память. Удобный TUI |
| [dstat](http://dstat) | Гибкая альтернатива vmstat/iostat, поддерживает плагины |
| [atop](http://atop) | Подробная статистика по процессам, включая диск и swap |
| [nvtop](https://github.com/Syllo/nvtop) | Только для GPU (упоминается для полноты картины) |
| [collectl](https://collectl.sourceforge.net/) | Лёгкий агент для сбора телеметрии, в том числе по дискам |
